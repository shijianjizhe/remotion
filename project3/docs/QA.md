| 检查 | 方法 | 结果 |

| 镜头表 | `scripts/validate-shots.mjs` | 28 个镜头，无空隙、无重叠，0→4200；25 条字幕均在所属镜头窗口内、每条停留 ≥ 2.5 s、每行 ≤ 20 字；S01/S04/S26 按 PRD 无说明字幕（S04 的文字即片名卡） |

| 无 BGM / 无人声 | 素材清单 | 全部为程序合成的 SFX，见 `assets-and-licenses.md` |

## 5. 已知限制（如实记录）

- 参考片分析基于每 3 秒一帧的抽样，没有逐帧检查（自带 ffmpeg 缺少 fps/select 滤镜）。
- S26 的点阵回忆按 PRD“快速但平滑”的要求设计，变形中途的几帧本身不可辨认，只有停留帧可以认出形状。
- 鞋、人物、剧院等都是原创线描与剪影，属于有意简化的“雕刻式”风格，不是写实插画。
