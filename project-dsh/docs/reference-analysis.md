# 参考片《运气的形状.mp4》美术分析

> 分析方式说明：本片制作环境中的模型不具备图像输入能力，**没有“用眼睛看”**参考片。
> 因此分析全部通过程序化测量完成（ffprobe 元数据 + 逐帧解码 + 亮度/墨量/色彩/运动能量统计 + 版式行列剖面），
> 所有结论都附带可复现的量化数据；未测量的内容（例如具体镜头里画的是什么物体、字句措辞）不作断言。
> 分析脚本：`scripts/analyze-ref.mjs`、`analyze-ref2.mjs`、`analyze-ref3.mjs`、`analyze-ref4.mjs`（中间数据在 `.analysis/`，不进入成片）。

## 1. 技术规格（ffprobe 实测）

| 项目 | 实测值 |
|---|---|
| 容器 / 编码 | MP4 / H.264 High profile (level 100) |
| 分辨率 | 1280×720，DAR 16:9，yuv420p |
| 帧率 | 30/1 恒定（avg = r_frame_rate = 30/1） |
| 时长 | 133.000 s，3990 帧 |
| 视频码率 | 约 909 kb/s（整片约 17.4 MB） |
| 音轨 | AAC-LC，44.1 kHz，立体声，约 128 kb/s，133.03 s |

参考片是**低码率的暗调短片**：码率不高，说明画面以大块平缓暗部＋少量高光细节为主，不是高频细节密集的画面。
这直接影响本片的渲染策略：**大形、少量高光、慢运动**，而不是满屏噪点和快速运动。

## 2. 影调（逐帧亮度统计，2 fps 采样 268 帧）

- 全片平均亮度（0–255 感知亮度）**12–25** 占绝大多数时间；仅两个瞬间冲到 36 与 43。
- `dark(<18)` 像素占比：**57%–95%**（多数时刻 75%–90%）。→ 画面一半以上接近黑。
- `bright(>90)` 像素占比：**1.5%–6.7%**（多数时刻 2%–4%）。→ 亮部是“少量点缀”，不是大面积受光。
- `hot(>200)` 像素极少（多数帧 0–150 个），只有高光点会到 200 以上。

**结论**：参考片是“黑底 + 稀疏高光”的水墨式暗调，不是“整体压暗的商业片”。
本片据此设定：背景 `#090908`，画面亮部控制在 1%–6%，`dark<18` 目标 45%–85%。
（自检时用 `scripts/inspect.mjs` 直接测量自己渲染的帧，数值见 `docs/QA.md`。）

## 3. 色彩

- 亮部均值色（>90 亮度像素的平均 RGB）随时间在 **#7c776b → #c6b48e → #928671** 之间游走：
  低饱和、偏暖、接近“旧纸/旧铜”的色相，**没有出现饱和的橙金或青色**。
- 采样全片最亮的 0.5% 像素，均值 **#f6fefe（R−G = −8，G−B = 0）**：
  最亮处是**近白的中性高光**，而不是金色高光。

**结论**：暖色只存在于中低调（羊皮纸、旧铜、暗金），**最高光用接近白的暖白**。
本片金币的镜面高光因此使用 `#FFF6E2 / #FFFDF2`，币体本身才是 `#C49A57 → #8C6B3E`。
（避免了“廉价金色镭射粒子”的观感，这也是 PRD 明令禁止的。）

## 4. 版式：行列墨量剖面（全片 134 帧平均）

把每帧中亮度 >55 的像素按行累加平均（单位：像素/帧）：

| 行位置（720p 下） | 占画面高度 | 墨量 | 判读 |
|---|---|---|---|
| y≈12–20 | 7%–11% | 11–16 | 左上/右上**角标注释带**（细小字） |
| y≈64–92 | 35%–51% | 22–33 | 主视觉主体 |
| y≈148–161 | 82%–90% | **41–56（全片最高）** | **底部说明文字带** |
| y≈172 | 95.5% | 25 | 极下缘还有一条信息（角标/页脚） |

列剖面（每 8 px 一列，0=左，320=右）呈中间高、两端低的形态，峰值集中在画面中部，右侧另有一个次级聚集。

**结论与换算（1080p 版式）**：
- 说明文字带中心约在画面 **82%–90%** 高度 → 本片取 `y≈908` 的中心、基线 `y≈936`；
- 角标注释带约在 **7%–11%** 高度 → 本片左上/右上从 `y=74` 起排；
- 主视觉集中在中部，且**亮部重心略低于画面中心**（见下节）。
本片不复刻参考片的像素坐标，只沿用这种“角注—主体—底注”的三层信息等级，字号与边距为本片原创（左/右安全边距 110 px）。

## 5. 构图重心

亮部（>70）像素的质心：x 常在 **43%–65%**（多在 52%–58%），y 常在 **42%–75%**（多在 50%–62%）。
→ 主体**略偏右下**，上方留给注释，下方留给字幕。本片主视觉中心取 (960, ~500–520)，符文/角注在其上，字幕在其下。

## 6. 运动节奏

以 0.5 s 为步长计算的帧间平均绝对亮度差（“运动能量”）：

- 中位数 **1.95**，均值 4.23，p90 **8.78**；
- 268 个半秒样本中只有 42 个超过 6（≈整片约 30–40 个“可辨画面变化点”）；
- 极大值出现在 **69.5–70.0 s（53.9 / 55.3）** 与 **125.5–126.0 s（73.9 / 72.9）**，即两处强转场（很可能是一次闪白/白场切换）；
- 131.0 s（41.0）之后，132 s 的帧平均亮度 43.2、`dark` 仅 1% → 片尾是一张**明亮的结尾卡**。

**结论**：参考片平均镜头长度约 3–4.4 s，绝大多数时间运动极缓（能量 <3），只用少数强转场打点。
本片因此：**28 个镜头 / 140 s（平均 5 s）**，镜头内以缓入缓出为主，每隔 5 秒至少出现一次可辨变化；
强反差只留在 S02 玻璃碎裂、S04 片名、S26–S28 收束这几处。

## 7. 借鉴与不借鉴（对照 PRD 第 2 节）

**借鉴（视觉语法）**
1. 近乎纯黑的底 + 局部暖光池 + 低密度浮尘（本片浮尘 26–34 颗，种子固定）；
2. “角注—主视觉—底注”的三层信息等级与字号梯度；
3. 亮部占比 1%–6%、最高光近白、暖色只在中低调；
4. 慢推 / 轻 orbit / 局部停顿的镜头语言，强转场极稀少；
5. 羊皮纸只作为“文献/账页”出现，不铺满整屏。

**不借鉴（明确避开）**
1. 不复刻任何具体构图、像素坐标、片头图案、字幕原文、Logo/水印；
2. 不提取原片音轨，不模仿其音乐；
3. 不使用原片画面（本片所有元素均为 SVG 程序化绘制 + 程序化纹理 + 程序化合成音效）；
4. 不使用荧光青/炫紫/科技蓝、霓虹 HUD、企业仪表盘渐变。

## 8. 参考片之外的自定美术决策（本片原创）

- **单一材质基因**：一枚“眼与桂冠”浮雕金币贯穿 S03–S28（片头出现、S06 付账、S10 由账簿收束而成、S11 变成钟、S16 上天平、S27 回收）。
  币面用同一套渐变与浮雕语言，倾斜时用 `scaleX=|cos|` 模拟转动，接近立边时切换为带齿纹的侧边，避免“贴图翻转”的廉价感。
- **暗金只给“重要物体与年号”**，其余用旧铜 `#826142` 与灰金 `#9B8A70`；
  枯红棕 `#763E32` 只用在“失去/封存”（S23 火漆印、S21 幕布），全片出现次数极少。
- **镜头不做假虚化**：参考片的景深靠真实镜头，本片用透明度/亮度层级 + 构图聚焦代替，避免文字虚焦。
- **纹理全部程序化生成**（羊皮纸 fBm、胶片颗粒、柔光贴片、暗角、墙面），无外部图片素材，授权干净。
