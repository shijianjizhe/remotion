> **检查方式的诚实说明**：本制作环境的模型不具备图像输入能力，无法“用眼睛看”。

## 6. 渲染确定性

同一帧两次独立渲染（同一进程、不同 concurrency）：

| 帧 | 结果 |
|---|---|
| 137 | identical（sha256 `3271787277000dd8`） |
| 1543 | identical（`110acfed56ae2b35`） |
| 2210 | identical（`703e55f24811987a`） |
| 3390 | maxDelta **2/255** on 724 px（0.035%）→ 文本抗锯齿抖动，肉眼不可见 |
| 4180 | identical（`25b152d9934dbd79`） |

帧 3390 的差异定位在 x[622,718] y[314,404]，正是 S23 火漆印里的中文小字；
4 次重复渲染中 3 次完全一致、1 次出现 ±2/255 的文本光栅差异。
**结论**：几何、布局、粒子、颜色、明暗全部确定；唯一不确定项是 Chrome 对极小字号文本的抗锯齿缓存，
因此 QA 门限写成“maxDelta ≤ 2/255 且差异像素 < 0.1% 视为通过”，并在 `scripts/qa.mjs` 中实现。

随机性来源：`src/lib/rng.ts` 的 `mulberry32` / `hash01`（固定种子）。
- `src/`（成片代码）：`grep -rnE "Math\.random|Date\.now|setTimeout|setInterval"` → **0 处命中**
  （唯一出现 `Math.random` 字样的是 `rng.ts` 里那句“禁止无种子 Math.random”的注释）；无 CSS 无限动画、无网络请求。
- `scripts/gen-sfx.mjs` / `mix-sfx.mjs`：同样 0 处；26 个 WAV 两次生成 SHA-256 逐字节一致。
- `scripts/gen-textures.mjs` / `verify-textures.mjs`：仅用 `performance.now()` 打印运行耗时（不参与像素生成），
  两次生成的 7 张 PNG 逐字节一致。
- 结论：**输出不受机器时钟、并行顺序、运行次数影响**；唯一例外是上表第 4 行的 Chrome 文本抗锯齿缓存。

## 9. 已知限制（不作粉饰）

1. **无法目视校对**：所有判断来自量化探针。若用户的显示器上出现肉眼可见的偏差（例如某个字距观感、
   某个材质不对味），属于本 QA 手段的盲区；`scripts/inspect.mjs` 可随时对任意帧复核。
2. 参考片的**具体镜头内容**（画面里到底是什么物体、文字写了什么）没有用眼睛确认，只做了统计特征层面的借鉴，
   因此本片与参考片的“像”是**影调与信息结构层面的像**，不是构图层面的像。
3. S26 的“元素回环”是最暗的一段（bright 0.39%），靠运动而非亮度承载；如果希望它更抢眼，可提高
   `src/scenes/06_Ending.tsx` 中 Motif 的描边宽度与粒子数。
4. 玻璃碎裂的“慢动作”是解析积分（`slowIntegral`）实现的减速，不是真时间重映射；
   视觉上等价，但与真实高速摄影的拖影不同（未加运动模糊，避免字符糊化）。
5. 未实现真正的 3D/WebGL 金属反射：金币的立体感来自渐变+高光+立边切换，属于“视觉相当”的替代方案。
