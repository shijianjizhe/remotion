# 素材来源与授权

本片所有画面元素**均为程序化生成**，没有使用任何外部图片、视频或采样音频。

## 1. 图像 / 纹理（`public/tex/`）

全部由 `scripts/gen-textures.mjs` 用 Node + sharp 以固定种子数值合成，可重复生成（两次生成的 SHA-256 完全一致）：

| 文件 | 生成方式 | 用途 |
|---|---|---|
| `parchment.png` | fBm 值噪声（5 倍频）+ 纤维条纹 + 软污渍 + 边缘烘色 | 羊皮纸文献/账页/档案卡 |
| `grain.png` | 固定种子白噪声 alpha | 低幅度胶片颗粒 |
| `glow-gold.png` / `glow-ember.png` | 高斯径向渐变 | 柔和光源贴片（避免逐帧 CSS blur） |
| `wall.png` | 低频 fBm + 细裂纹 | 1850 店铺墙面 |
| `vignette.png` | 椭圆径向 + 抖动 | 极轻暗角 |
| `venue-haze.png` | 多个大尺度软斑 | 剧院空气感 |

授权：**本项目原创，无第三方权利**。

## 2. 矢量图形

金币、窗、账簿、天平、票券、剧院、钟面、路径、徽章等全部为手写 SVG / React 组件（`src/components`、`src/scenes`）。
玻璃碎片与裂纹由 `src/lib/shatter.ts` 按固定种子生成径向+同心网格，相邻碎片共享顶点，属原创几何。**未导入任何图标库或现成矢量素材。**

| Noto Serif SC（思源宋体） | `public/fonts/NotoSerifSC-VF.ttf`（25.1 MB，可变字重 100–900） | **SIL Open Font License 1.1**，允许嵌入与再分发 | 从本机 `C:\Windows\Fonts\NotoSerifSC-VF.ttf` 复制，未作修改；中文/数字/拉丁统一使用该字体，无网络字体依赖 |

未使用任何专有受限字体（微软雅黑、宋体等仅存在于系统，未被复制进工程）。

## 4. 声音（`public/sfx/`，26 个文件）

全部由 `scripts/gen-sfx.mjs` 用纯 JS 数值合成（正弦/非谐分音、滤波噪声、颗粒化包络），48 kHz / 16-bit / 单声道，
在 96 kHz 下生成后再用多相滤波降采样到 48 kHz 以避免混叠。固定种子，重复生成哈希一致。

- **没有**任何下载的采样包、录音、参考片音轨或音乐片段；
- **没有**人声、对白、可辨识语义的人声（`crowd-murmur` 为带通噪声的多重慢包络，实测 87% 能量在 250–2 kHz、0% 高于 8 kHz，无语音共振峰）；
- **没有**背景音乐。

授权：**本项目原创，无第三方权利**。
