### 必须遵守的创作原则

1. **全片没有旁白、口播或 TTS。** 故事由动作、镜头、少量文字、音乐与音效共同讲述。禁止用大段字幕代替配音。
2. **只采用一种主视觉风格：09 拼贴剪纸。** 可以在此基础上大胆创新，形成统一的纸片、印刷、手工拼贴与超现实场景语言。

6. 不编造全人群观看时长、上瘾机制等未经证实的数据；这里的三个小时是主角的一段虚构经历。
7. 不使用他人平台 Logo、受版权保护的视频界面截图或未经授权的音乐素材；所有元素维持原创审美。
8. Agent 可以自由调整镜头数量、镜头时长、转场、音乐和任何实现方式；**本文件只规定观众最终看到和听到的效果，不限定代码结构、技术选型或函数写法。**

**最终目标：** 一条即使完全没有解说，也让人愿意一口气看完的、带一点幽默和不安的艺术化短片。

## 1. 创意定位与参考

- 参考：<https://github.com/Vincentwei1021/mg-styles-15>
- 参考风格：09 Collage / Cut-out；只把仓库当作灵感，不必机械复刻。
- 核心概念：**“最后刷一个”，实际上是一场自己没有察觉的时间盗窃。**
- 视觉情绪：开头生活化、轻快；中段荒诞、越发失控；末段骤然安静，留下后劲。
- 避免：赛博朋克霓虹、常规扁平矢量科普、全屏手机无限滚动、数据图表堆砌、只有字幕切换的 PPT 感。

### 四种贯穿全片的视觉符号

**纸片卧室**：卧室由不同纸质的床、窗、台灯、枕头和人物拼贴而成。空间和布局始终能辨认，让观众有熟悉的生活代入感。

**可以被偷的纸钟**：时钟时间不仅跳数，还能被神秘的手从钟面上“撕走”。被撕开的地方露出破纸边和底层旧纸。

**神秘剪纸手**：刚开始躲在画面边缘，动作轻巧、带一点滑稽；到后期越来越肆无忌惮，把整块钟面扯下来。

**时间碎片堆**：被偷的时间不消失，而是留在房间里，越来越多，最后包围着还在刷手机的主角。

| 运动 | 手工定格的质朴感，动作有预备、接触、撕裂、掉落和后续反应；不必追求机械丝滑 |

## 3. 绝对重要：动态密度与留存节奏

这条视频最大的风险不是不够炫，而是**动画播完了，镜头还在原地静止好几秒**，观众就会划走。

### 3.1 核心剪辑原则

- **动作完成后立即进入下一拍。** 撕纸落定、纸牌翻完、文字出现完后，及时让下一事件衔接；不要把已完成的动作当作静态插画放在那里。
- **每个镜头都要持续推进故事。** 只有一个新信息、但没有运动或情绪变化的镜头，应压短或删除。
- **不要按表格机械填满每一秒。** 下方时间段是结构参考，不是要求 Agent 强制让画面停留到某个秒数。
- **优先快进入、快表达、快离开。** 一个想法表达清楚之后就切走，宁可成片更短，也不要让观众等待。
- **要有快慢对比，而不是全程无休止乱动。** 有意义的短暂停顿可以保留，例如凌晨两点突然静下来、主角意识到失去三小时。但这种停顿必须有心理张力或细节变化，不是渲染结束后空等。
- **信息可读 ≠ 画面不动。** 23:40、00:30、01:20、02:00 等重要信息可以短暂保持可读，同时让纸屑落下、人物抬眼、阴影移动或镜头继续运动。

### 3.2 一个具体的合格 / 不合格案例

**不合格：** 时钟翻到 23:40 用了 0.5 秒，之后维持完整静态画面 3 秒，等这一镜的预定时长走完才切换。

**合格：** 时钟翻到 23:40 → 主角没注意 → 镜头立即跟着被撕下的纸片掉到地上 → 纸堆增加 → 下一次上滑开始。每次运动之间存在自然的视觉接力。

**不合格：** 结尾文案完整出现后，保持无变化 4 秒等视频结束。

**合格：** 字出现时拉远仍在发生、纸片最后落地、观众刚看明白整体构图便自然结束。最后可以有**短而有意图**的余韵，不做无效尾帧。

### 3.3 审核方法

完整审片时，专门寻找“动作已经结束，但画面没有任何新的信息或变化”的段落。凡是明显拖沓的地方：**先剪短，再考虑新增动作，而不是为了填时间硬塞特效。** 视频实际长度完全可以因此缩短。

## 4. 无旁白叙事：文字与声音如何分工

**不制作、也不预留任何旁白音轨。** 也不使用 AI 配音朗读字幕。

屏显文字建议只保留这些关键节点，可按实际效果进一步删减：

| 位置 | 建议屏显 | 作用 |
|---|---|---|
| 开头 | **「最后刷一个，就睡。」** | 一秒建立日常困境和人物动机 |
| 开始 | **23:00** | 清楚锚定起点 |
| 中段 | **23:40 → 00:30 → 01:20** | 直接呈现时间流逝，无须任何解释 |
| 末段 | **02:00** | 形成反差与情绪落点 |
| 结尾 | **「你刷走的，不只是下一个视频。」** | 可保留，也可由画面反转承担，不能占据太长尾镜 |
| 品牌 | **如果放映局** | 低调落款，不另设漫长片尾 |

不需要在每个镜头配一段文字。某些场景只靠手势、钟表和纸片音效即可成立。

### 声音设计原则

- **每一次上滑，都尽量伴随一声纸张被撕走的音效。** 让观众建立潜意识联系。
- 前期：轻快、有一点滑稽的纸拍、手指触碰、木质敲击节奏。
- 中期：纸张撕裂和翻页更密、更重，音乐逐步加压，但不要变成惊悚片。
- 高潮：一记最大面积撕裂与纸片坠落，建立明显的声音顶点。
- 末段：音乐突然抽空，留下微弱房间声、纸片轻落声，突出 02:00 的意识回归。
- 反转：小偷和主角的动作音效合为一次，让两者关联自然显现。
- 静默用于情绪，不可用来掩盖视觉上的长时间空白。
- 音乐和音效必须是原创、有授权或可用于发布的资源；不要直接使用没有许可的热门歌曲。

## 5. 导演分镜（结构参考，可主动重剪）

> **重要：时间仅表示建议区间，并非要求死守的时长。镜头完成表达就应切走。** 最终总时长以节奏为准，不要求严格凑够 60 秒。

| 段落 | 建议区间 | 画面与行动 | 节奏重点 |
|---|---|---|---|
| 01｜一句谎言 | 0–4s | 夜晚纸片卧室；钟面 **23:00**，主角准备睡觉却拿起手机；纸条「最后刷一个，就睡。」快速出现 | 直接开始，不加冗长片头；0.5 秒内给出明确动作 |
| 02｜第一次偷取 | 4–10s | 主角拇指第一次滑动；黑色纸片手悄悄伸出，抓住时钟的一角，将一块“时间”撕下；钟面出现缺口 | 动作连续：滑 → 抓 → 撕 → 落；无需每步之后停顿展示 |
| 03｜变成习惯 | 10–18s | 几张不同内容的原创短视频纸卡快速换过；每刷一次，时钟被偷一块；主人仍无知觉 | 每张内容卡短暂出现，快速形成重复的荒诞节奏；避免机械循环 |
| 04｜第一个意外 | 18–25s | 23:00 的纸面被撕开，露出 **23:40**；主角手指还在滑；纸片落到地面，镜头跟着下行，首次显示积累的碎纸 | 让时间可读，但镜头不要因数字停住而静止 |
| 05｜越陷越深 | 25–35s | **00:30、01:20** 依次露出；主角姿势变疲惫，窗外更暗；纸片越积越多，偷窃动作越来越夸张 | 画面不断被新行为推动，节奏逐渐加快；每一跳变化都必须有新意 |
| 06｜失控高潮 | 35–44s | 巨大的黑色手直接掀起钟面甚至卧室的夜幕，一大片时间纸块塌落，房间被纸屑吞没；主角还在机械上滑 | 全片最强动作和声音高点；不要在高潮结束后空停 |
| 07｜醒过来 | 44–51s | 音乐骤停，主角终于抬头；残缺纸钟只剩 **02:00**。手机渐渐放下，最后的碎纸慢慢落地 | 允许有意义的“安静”，但必须持续有人物情绪或末尾纸片动作 |
| 08｜小偷是谁 | 51–56s | 主角手指的滑动姿势与神秘剪纸手的轮廓/运动轨迹重合；观众意识到偷窃与自己有关 | 一个准确、有力的视觉反转即可，不冗长讲解 |
| 09｜最后一眼 | 56–60s 左右 | 相机拉远：床、人物和残缺时钟被三小时的纸片包围；一句短文案和「如果放映局」自然出现 | **拉远过程中完成落版，结束即切断；不让静止片尾拖数秒** |

### 视觉连续性

- 从 23:00 到 02:00 是跨午夜的 **180 分钟**，时间顺序不能乱。
- 时钟缺口和房间中的纸片堆积原则上只增加、不凭空恢复。
- 主角、卧室布局、衣着、手机朝向要保持连续。
- 观众要能在不看文字解释的前提下理解：手机一滑，时间就被“偷走”。
- 剪纸手的造型、运动方向与结尾对应关系应提前埋伏笔。

## 6. 三个需要特别打磨的名场面

### A. 第一次被偷

不靠文字说明。拇指刚划过屏幕，画面另一头的纸片手立刻伸出来，撕下纸钟的一角。一片时间纸掉落到地面，并留下清楚的钟面缺口。这个动作必须一眼能懂，是整片的“语法教学”。

### B. 把整块夜晚撕掉

前面只偷时间碎片，到了高潮，神秘手索性抓住整个钟面连带深蓝色窗外夜幕一起掀起。被撕掉的不是小数字，而是主角本来可以睡觉的整段夜晚。画面可以大胆、荒诞，但视觉仍然是剪纸拼贴，不变成科技大片。

### C. 小偷的反转与最后拉远

镜头里主人还保持滑动手势，神秘手也做一模一样的动作，两只纸片手在构图或运动中重合。接着镜头拉远，整个房间已被时间碎片淹没，而主角只是画面中很小的一个人。**这里的情绪来自发现，不来自旁白解释。**

## 7. Agent 的制作流程（不限定实现方法）

**第一阶段：创建独立新工程并确定视效。** 从零创建本片专用的 Remotion 工程；先制作纸片卧室、人物、神秘手、纸钟和时间碎片的统一美术样张。风格看起来不能只是扁平 UI 加旧纸滤镜。

**第二阶段：验证核心动作。** 优先做一次完整的“滑动 → 偷取 → 撕裂 → 碎纸落地”动作，以及结尾手势同步的反转。若这两段不清楚，先修改，不急着填满整条视频。

**第三阶段：完成剪辑粗版。** 让全部情节从 23:00 走到 02:00。第一次观看时就检查哪些场景动作停止后仍拖着不切；大胆压缩这些空白。关键叙事不应依赖文字补救。

**第四阶段：加入声音与精修。** 让滑动和撕纸形成条件反射般的声画联系，高潮有起伏，末段有有效的安静。检查人物表情、纸张层次、场景转场和节奏对比。

**第五阶段：完整渲染与观看检查。** 至少看两遍：一次关声音验证故事，一次正常听声音验证节奏。根据实际观看感受修正，交付完成的视频、核心关键画面及简短问题报告。

Agent 对镜头时长、内容安排、动画手法、工程组织、工具和参数**拥有自主决定权**；若发现更好的画面表达可以优化原分镜，只要不破坏核心创意、单一风格、无旁白和动态密度原则。

## 8. 质量验收标准

### 叙事与留存

- [ ] **全片零旁白、零 AI 配音、零口播**；无解说也能理解故事。
- [ ] 开场立即有动作和场景信息，不以慢长片头浪费注意力。
- [ ] 第一次滑动与时间被偷走的因果明确。
- [ ] 时间推进到 **02:00** 的情绪反差足够清楚。
- [ ] 反转通过画面成立，而非靠一大段说明。
- [ ] **逐段检查：任何动画结束后，没有无意义的静止停留。**
- [ ] 一旦画面表达完毕，及时切换；如果全片因此不足 60 秒，也不补空镜头。
- [ ] 必要的停顿都存在细微动作、镜头运动、信息发现或情绪变化。

### 美术与声音

- [ ] 全片只有 09 拼贴剪纸一种统一的风格语言。
- [ ] 纸张、剪裁边、印刷纹理、贴纸阴影与手工定格气质清晰。
- [ ] 关键动作有抓取、接触、撕离、坠落的表现，不只是简单平移图层。
- [ ] 人物从清醒到疲惫的变化看得见。
- [ ] 音效准确辅助视觉动作，音乐有节奏层次，不轰炸。
- [ ] 文字极少、易读，主要依靠画面讲故事。
- [ ] 竖屏显示时主要视觉内容不被平台按钮和底部描述遮挡。
- [ ] 无无授权素材、无真实平台 Logo 或原样搬用的他人视频。

### 完成度

- [ ] 提供能正常播放的完整竖屏成片，并检查无明显黑帧、画面缺失、声音异常。
- [ ] 提供若干代表性关键画面，包括首次偷取、高潮、手势反转、最后拉远。
- [ ] 提供简要制作说明、素材来源和实际修订记录。
- [ ] 不以静态分镜图、技术 Demo 或仅跑通工程代替最终视频。

## 9. 自由发挥与最后的导演提醒

你可以改变具体场景、增加黑色幽默、替换一些象征性镜头，也可以提出比“撕纸钟”更有力量的同风格隐喻。仓库里的 09 只是风格起点，**不是创意上限**。

但请牢牢记住：**无旁白、视觉因果明确、镜头有生命、已停止的动画不拖沓、全片只用一种主风格。**

最后不要把结尾做成静止海报展示。让反转、拉远、文案与结束节奏一气呵成；观众刚看明白失去的三个小时，就应该自然地迎来结尾。
