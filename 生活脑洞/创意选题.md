# Remotion 短视频创意选题库（30 题）

> **用途**：长期保存、检索、筛选创意。以后只需说「讨论 06 号」「为 16 号写 PRD」「对比 01、04、21 号」，即可用固定编号继续创作。
>
> **版本**：v1.0｜2026-10-28  
> **范围**：本库仅收录本轮整理的 30 个生活 / 职场 / 家庭 / 财经 / 社交类 Remotion 创意。另行讨论的《时间并不均匀》《看不见的代价》等理论纪录片系列不计入这 30 题。  
> **说明**：以下数据、人物、故事均为创意设定或演示样例，**不得冒充真实统计或未经核实的研究结论**。

## 使用方法

- **按编号找**：如「帮我把 **03｜一场毫无意义的会议，到底烧掉多少钱？** 做成 60 秒分镜」。
- **按主题找**：如「从家庭题材里挑一个制作成本低、情绪强的」。
- **按状态管理**：每个选题的 `状态` 可改为「待讨论 / 方案中 / 制作中 / 已发布 / 暂缓」。
- **进入制作时**：从本库中选一个选题，另建该选题的 `prd.md`、`storyboard.md` 和素材目录；不要在总清单中堆完整分镜。

## 二、第一梯队：最想尝试的 8 个创意

### 01｜如果你的人生有一张年度账单
- **类型**：强共鸣｜时间 / 人生
- **核心设定**：一张巨大的年度账单展开：今年睡觉 2920 小时、上班 2200 小时、刷手机 1100 小时、陪父母 48 小时……
- **Remotion 视觉核心**：账单从打印机中延伸成全年时间轴；数字跳动，时间块依次占满一整年；最后所有时间碎片重新汇总。
- **结尾钩子**：「这一年，你真正留给自己的时间有多少？」
- **制作注意**：数字仅为设定人物的虚构样例；分类要互斥，合计 8760 小时（非闰年）；不能把剩余时间随意等同于“自己的时间”。
- **状态**：待讨论

### 02｜你的工资，是怎么在发工资当天消失的？
- **类型**：有趣又真实｜财经 / 生活
- **核心设定**：工资到账 10000 元，房租拿走 3000，吃饭拿走 1800，交通、账单、购物、订阅接连冲来“抢钱”。
- **Remotion 视觉核心**：工资数字从 10000 逐级递减；拟人化的账单从多个方向冲入，钱被分割、吸走；现金流可视化。
- **结尾钩子**：「原来我只是工资的中转站。」
- **制作注意**：收支为虚构人物案例，支出合计需和余额精确相符。
- **状态**：待讨论

### 03｜一场毫无意义的会议，到底烧掉多少钱？
- **类型**：职场吐槽｜职场
- **核心设定**：十个人开会，讨论十分钟“要不要开会”，三十分钟后决定“下次再议”。
- **Remotion 视觉核心**：会议室小人就座，屏幕上的成本计价器按秒上涨；会议事项反复循环；会议结束只留下下一次会议的日程。
- **结尾钩子**：「本次会议耗资：¥862。产出：下次会议时间。」
- **制作注意**：¥862 是创意示例，不是通用事实；金额按人数、假设薪酬和耗时计算并标注假设条件。
- **状态**：待讨论

### 04｜如果一家人也有一份年度报告
- **类型**：情绪触动｜家庭
- **核心设定**：家庭群消息 876 条、视频通话 42 次、一起吃饭 8 次；最常说的话是「下次回去再说」。
- **Remotion 视觉核心**：年度报告卡片、聊天记录气泡、通话波形、餐桌座位；最后数据消隐，剩下一张全家福。
- **结尾钩子**：不用说教，让照片和沉默完成表达。
- **制作注意**：全部数据以虚构家庭为例；保护真实亲属隐私。
- **状态**：待讨论

### 05｜一个人是怎么被一分钟的视频偷走三个小时的？
- **类型**：反常识｜互联网 / 生活
- **核心设定**：「最后刷一个就睡觉。」23:00 → 23:40 → 00:30 → 02:00，时间快速流走。
- **Remotion 视觉核心**：手机界面无限向上滚动，短视频像传送带；背景卧室由夜晚变成凌晨；时间数字越来越快。
- **结尾钩子**：镜头拉远，手机屏幕是一条看不到尽头的传送带。
- **制作注意**：不需要引用没有依据的“每个人平均刷多久”数据。
- **状态**：待讨论

### 06｜如果五年后的两个你，同时给现在的你发消息
- **类型**：剧情反转｜人生
- **核心设定**：两个未来的自己发来不同的消息：A「谢谢你五年前做了这个决定」；B「如果当年你没有那样选就好了」。
- **Remotion 视觉核心**：屏幕分裂为左右两条时间线，生活轨迹同时推进；同一个人经历两种不同选择与后果。
- **结尾钩子**：两个未来都不完美，都有自己的遗憾。
- **制作注意**：不同未来为虚构叙事，不是对人生因果的科学证明；重点在平行剪辑的一致性。
- **状态**：待讨论

### 07｜一张100元人民币的奇妙旅行
- **类型**：财经故事｜财经 / 社会
- **核心设定**：用 100 元买饭 → 店主支付供应商 → 供应商发工资 → 工人在另一家店花钱。
- **Remotion 视觉核心**：同一张钞票穿行于街道、商铺、人物之间；交易像连接城市的发光线。
- **结尾钩子**：「对你来说是消费，对另一个人来说可能是收入。」
- **制作注意**：资金循环应避免暗示一张钞票可凭空创造财富；可用拟人化纸钞作视觉主角。
- **状态**：待讨论

### 08｜如果父母和孩子交换成绩单
- **类型**：教育话题｜家庭 / 教育
- **核心设定**：孩子数学 92 分仍被批评；家长收到自己的成绩单：倾听孩子 58 分、控制情绪 61 分、兑现承诺 70 分。
- **Remotion 视觉核心**：成绩单翻转成镜子，分数逐项落下；传统红笔批改变成双向评估。
- **结尾钩子**：「为什么你可以要求我考满分？」
- **制作注意**：成绩单评分是寓言设定，不要表现为客观权威测量。
- **状态**：待讨论

## 三、第二梯队：现实生活游戏化（09—14）

### 09｜假如成年人也有血条和技能树
- **类型**：游戏化｜职场 / 生活
- **核心设定**：熬夜扣精力，迟到扣信誉，发工资加金币，房贷扣金币；普通周一变成闯关游戏。
- **Remotion 视觉核心**：HUD、血条、状态栏、等级提示、技能树；各类现实事件触发数值变化。
- **结尾方向**：让“成年人没有新手教程”形成幽默收束。
- **状态**：待讨论

### 10｜假如人生可以查看撤回的消息
- **类型**：游戏化 / 情感｜社交
- **核心设定**：朋友、领导、暗恋的人都撤回过消息；获得超能力后可以看见原话，却发现意料之外的内容。
- **Remotion 视觉核心**：聊天界面、撤回动画、被遮盖文字逐字显影、记忆闪回。
- **结尾方向**：某句撤回的话引发温柔或意外反转。
- **状态**：待讨论

### 11｜如果人际关系能显示电量
- **类型**：游戏化 / 共鸣｜人际关系
- **核心设定**：刚认识的朋友 100%，多年未联系的同学 7%，互相消耗的人出现红色警告。
- **Remotion 视觉核心**：人与人之间的电量连接线、充放电动画、关系能量网络。
- **结尾钩子**：一个电量不高的人，却总在主动为你充电。
- **制作注意**：电量是隐喻，不把人际关系简化为可测的真实数值。
- **状态**：待讨论

### 12｜如果所有人的头顶都显示真实心情
- **类型**：游戏化 / 情感｜社会
- **核心设定**：微笑同事头顶写着「快撑不住了」，严肃的父亲写着「很想念孩子」，光鲜的人也有自己的困难。
- **Remotion 视觉核心**：城市群像、人物头顶的情绪状态粒子、表面表情与内心文字反差。
- **结尾方向**：强调理解他人，而不是妄断他人。
- **状态**：待讨论

### 13｜如果人生也有版本更新日志
- **类型**：游戏化 / 成长｜人生
- **核心设定**：`V1.0 出生 → V6.0 学会骑车 → V18.0 高考 → V23.0 第一次失业 → V28.0 学会与自己和解`。
- **Remotion 视觉核心**：版本发布记录、人生时间轴、版本升级的过渡动画、修复 Bug 和新增功能。
- **结尾方向**：没有“最终版本”，人生仍在更新。
- **状态**：待讨论

### 14｜假如人生所有决定都可以 Ctrl+Z
- **类型**：游戏化 / 剧情｜人生
- **核心设定**：不断撤回尴尬、考试失利、感情遗憾，但每次撤回也改变其他美好的事。
- **Remotion 视觉核心**：时间倒放、场景图层回退、分支节点重新连线、版本差异叠加。
- **结尾方向**：撤回并不等于拥有完美人生。
- **状态**：待讨论

## 四、第三梯队：适合评论区讨论（15—30）

### 15｜为什么你工资翻倍了，却感觉更穷？
- **领域**：财经
- **核心设定**：两个阶段的工资与生活支出并行增长，收入提高而结余未必增加。
- **Remotion 视觉核心**：双列收支账单同步膨胀、住房与生活成本挤占收入。
- **制作注意**：用假设家庭预算，不宣称必然规律。
- **状态**：待讨论

### 16｜如果所有商品都标上你需要工作几小时才能买到
- **领域**：财经 / 消费
- **核心设定**：所有价格标签从人民币自动切换为需要工作的小时数。
- **Remotion 视觉核心**：商品标签变成时间沙漏，购买行为直接消耗时间刻度。
- **制作注意**：小时数基于明确假设的税后时薪或可支配收入计算。
- **状态**：待讨论

### 17｜一场婚礼究竟会让多少钱流动？
- **领域**：财经 / 社会
- **核心设定**：婚礼上的餐饮、摄影、布置、服装等支出逐项流向不同参与者。
- **Remotion 视觉核心**：婚礼现场缩小为经济流动地图，金币随服务链条移动。
- **制作注意**：模拟资金流而非笼统断言婚礼“产生了多少经济价值”。
- **状态**：待讨论

### 18｜领导说的“简单改一下”，到底有多复杂？
- **领域**：职场
- **核心设定**：一个按钮的微小改动，逐渐分裂成设计、接口、测试、兼容、部署等几十项需求。
- **Remotion 视觉核心**：任务节点自我复制，依赖关系无限延展；最初的小按钮被复杂流程包围。
- **结尾方向**：一句「简单改一下」引出庞大工作树。
- **状态**：待讨论

### 19｜如果招聘广告有一个真实翻译器
- **领域**：职场
- **核心设定**：招聘用语被夸张而幽默地翻译成打工人能理解的语言。
- **Remotion 视觉核心**：文本翻译器、词条扫描、标签翻转、招聘页面变形。
- **制作注意**：明确为幽默讽刺，不能将个别用语一概等同于企业的不良实践。
- **状态**：待讨论

### 20｜如果老板能看到每个人的隐形工作量
- **领域**：职场
- **核心设定**：表面平静的员工头顶，逐渐堆积协调、沟通、返工、救火等看不见的任务块。
- **Remotion 视觉核心**：任务方块堆叠、重量感与重心晃动、隐形流程显形。
- **状态**：待讨论

### 21｜一个孩子的周末，是怎么被填满的？
- **领域**：家庭 / 教育
- **核心设定**：原本空白的周末日历，逐渐被补课、练习、兴趣班、作业塞满。
- **Remotion 视觉核心**：空白日历高速填充，时间被压缩，最后仅剩一道极窄的休息缝隙。
- **结尾方向**：留出一个未被占用的小时，作为情绪停顿。
- **状态**：待讨论

### 22｜如果父母能重新体验一次你的童年
- **领域**：家庭 / 情感
- **核心设定**：父母沿着孩子过去的成长时间线重新经历关键时刻，理解当年的感受。
- **Remotion 视觉核心**：两条年龄时间线逐渐交汇，同一个空间叠放不同年代记忆。
- **状态**：待讨论

### 23｜为什么一个考90分的孩子，会比考60分更难过？
- **领域**：教育 / 心理
- **核心设定**：同样的评价场景中，不同期待值使分数呈现不同的心理意义。
- **Remotion 视觉核心**：分数柱与期待值标尺交错，90 分因未达到期待而变暗。
- **制作注意**：属于情景化心理叙事，不把这种体验描述成人人如此的普遍法则。
- **状态**：待讨论

### 24｜如果学校教的不是考试，而是如何生活
- **领域**：教育
- **核心设定**：两份不同的课程表对照：传统考试科目和财务、沟通、情绪、生活技能等课程。
- **Remotion 视觉核心**：传统课表旋转为另一套人生课程地图，科目逐一生长成真实场景。
- **状态**：待讨论

### 25｜一条“在吗”，为什么能让成年人紧张？
- **领域**：社交 / 职场
- **核心设定**：收到一句「在吗」，脑海里立刻生成借钱、加班、求帮忙等各种小剧场。
- **Remotion 视觉核心**：消息气泡展开成快速切换的平行小剧场；最后揭晓真实来意。
- **状态**：待讨论

### 26｜如果你说过的每一句伤人的话都有重量
- **领域**：情感 / 社交
- **核心设定**：刺耳的语言变成看得见的石块，逐渐堆在另一人身上。
- **Remotion 视觉核心**：文字实体化、石块坠落、人物背负重量，善意话语则可能产生不同视觉反应。
- **状态**：待讨论

### 27｜一个谣言是如何从1个人传到100万人？
- **领域**：互联网 / 社会
- **核心设定**：一条未经证实的消息，从单个节点经转发网络逐渐扩散。
- **Remotion 视觉核心**：点线关系网络扩展、传播路径亮起、少数高连接节点加速扩散。
- **制作注意**：任何传播规模、时间和传播率需说明为模拟参数，避免捏造真实案例。

### 28｜如果你的购物车会说话

- **核心设定**：购物车里的商品逐一开口，调侃冲动消费、情绪消费、囤货等购买动机。
- **Remotion 视觉核心**：购物车商品拟人化、弹幕式对话、结账前的辩论剧场。
- **状态**：待讨论

### 29｜如果每一次拖延都会收到一张罚单
- **领域**：生活 / 自律
- **核心设定**：每一次「明天再说」，屏幕就生成一张标注错过机会、时间成本的罚单。
- **Remotion 视觉核心**：罚单不断叠加、倒计时归零、未完成任务实体化。
- **制作注意**：罚款仅为视觉隐喻，不将假设机会损失冒充精确金额。
- **状态**：待讨论

### 30｜如果所有人的职业突然互换一天
