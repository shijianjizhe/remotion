# 《时间并不均匀》制作级 PRD

> 版本 V2.0｜2026-10-26｜交付对象：Codex / Claude Code 开发智能体

## 0. 一句话任务
制作一条 **1920×1080、16:9 横屏、30fps、约 150 秒、无旁白、无最终 BGM** 的历史科学视觉短片《时间并不均匀》。以用户提供的《运气的形状.mp4》为美术与节奏参考，围绕 **8 个知识节点**，用深黑、暗金、羊皮纸色、年份、历史文献、精密图形与真实可解释的实验动画，表现从绝对时间观到相对论，再到主观时间和记忆时间的认知变化。**最终视频保留音效，BGM 由用户后期添加。**

## 1. 优先级与不可妥协项
- P0：横屏 16:9；无任何配音；8 个知识节点；科学叙述准确；无版权不明的音乐；完整渲染 MP4。
- P0：全片统一历史科学纪录片视觉系统；禁止网页卡片轮播、普通 PPT、蓝紫赛博风、无意义粒子特效。
- P0：每个知识点必须有“现象 → 可见实验 → 结论”的视觉闭环；不依赖大段字幕。
- P1：画面设计、运动曲线、音效同步与细节打磨；兼容后期加入参考视频风格的配乐。
- P2：可复用的时间轴、时钟、历史注释、粒子、实验组件。

## 2. 参考视频分析与使用约束
开发前先完整观看用户同时提供的 `运气的形状.mp4`，按 5–10 秒间隔抽帧并记录：构图、字体、年份位置、注释、镜头运动、光效、粒子密度、转场方式和节奏。**仅借鉴视觉语法，不逐镜头复制**。重点观察：
1. 深黑空间与低对比羊皮纸肌理；暗金高光仅用于关键信息。
2. 左上年份、边缘文献式注释、中央实验主体、底部一句话解释的版式秩序。
3. 图形并非单纯展示，而是在镜头中“被推导出来”。
4. 片头片尾的视觉母题呼应。

参考片若不能读取，先告知用户并用本 PRD 的视觉规范继续；不得假称已完整观看。

## 3. 观众与传播目标
- 目标：无旁白也能看懂 8 个节点的大意，产生“原来时间还能这样理解”的认知惊喜。
- 首 5 秒建立悬念；每 10–20 秒产生新视觉变化；最终回到最初的钟。
- 成功不是信息越多越好，而是每个节点有独立可复述的结论。
- 发布渠道：用户个人账号；不加入「如果放映局」标识。

## 5. 核心叙事边界
**三个不同层次不可混淆**：
- 物理时间：真实钟表在不同运动与引力条件下积累的走时差异。
- 主观时间：大脑对瞬间持续时间的感受，并非物理秒钟改变。
- 回顾时间：记忆中的事件结构影响事后对一段经历长短的判断，并非“新鲜事越多就一定越长”。

避免说“宇宙每处的一秒都不一样”这类不精确断言；应表述为“不同路径或引力条件下的时钟，重新比较时可能出现走时差”。

## 6. 8 个节点与科学准确性
| # | 知识节点 | 历史锚点 | 核心观众结论 | 可视化 |
|---|---|---|---|---|
| 1 | 牛顿绝对时间观 | 1687 | 经典框架把时间当成独立、均匀的背景 | 同步钟阵与笔直时间轴 |
| 2 | 狭义相对论 | 1905 | 相对运动状态会影响钟表比较结果 | 两钟分离、相对运动、重逢对比 |
| 3 | 广义相对论与引力钟差 | 1915 | 不同引力势位置的时钟走时不同 | 高低两钟、等势线、走时差 |
| 4 | 哈菲尔—基廷原子钟实验 | 1971 | 飞机带钟环绕地球后出现纳秒级差异 | 地球、东西向航线、时钟读数 |
| 5 | GPS 相对论校正 | 现代 | 卫星钟需要校正才能支持精确定位 | 卫星、地面钟、误差扩散再收敛 |
| 6 | 停钟错觉 Chronostasis | 现代认知研究 | 眼球扫视后的首个视觉瞬间可能显得更长 | 快速转视、秒针停顿、视知觉补偿 |
| 7 | 自由落体时间知觉实验 | 2007 | 惊险经历事后显得更长，不代表视觉分辨率提升 | 下坠轮廓、真实计时与主观回忆并列 |
| 8 | 事件分段与回顾时间 | 认知心理学研究 | 事件边界与记忆组织影响事后时长判断 | 相同 365 天、不同记忆切片 |

**重要修正**：节点 2 的对比应呈现可重新比较的时钟路径，不能只让“静止钟 vs 运动钟”简单播放并声称某个绝对参考系的时间更慢。节点 3 的弹性网格只是帮助理解的比喻，不能把网格凹陷当作引力的完整解释。节点 4 可标注历史实验数值（向东约 -59ns，向西约 +273ns），但必须注明相对于参考时钟及误差范围；若无法验证数值则只展示方向和量级。节点 5 的卫星钟净效应约每天快 38 微秒，若展示具体数字必须标注为典型近似值。节点 7 禁止写成“人在危险时大脑处理速度一定变快”。

## 8. 画面设计系统（重点）
### 8.1 色彩令牌
- 底色：`#09090A` / `#11100E`，避免死黑导致层次消失。
- 暗金：`#B89658`；高光金：`#D6B878`，只强调关键数字、路径与节点。
- 羊皮纸：`#D8C7A5`；浅色说明字：`#EEE5D5`。
- 金属灰：`#756F65`；暗铜：`#76523A`。
- 金色发光半径受控，禁止大面积金光覆盖文字。

### 8.2 构图与安全区
- 1920×1080；重要信息保持距左右边缘 ≥100px、上下 ≥70px。
- 主体实验占中间约 60–70% 画幅；顶部历史标签、底部说明各有独立留白。
- 一屏最多一个主实验、一条主结论、一组次级注释；严禁同时出现 5 张卡片。
- 图像焦点随镜头运动，但每一幕有稳定的视觉锚点。

### 8.3 字体系统
- 中文标题：优先可合法使用的思源宋体/Noto Serif CJK；说明：思源黑体/Noto Sans CJK。
- 英文与年份：经典衬线字形；字号、字距和大小写保持一致。
- 片名建议 64–86px；年份 26–34px；知识点标题 30–42px；结论 30–38px；边缘注释 16–22px（1920×1080）。
- 字体实际渲染检查缺字与回退，禁止直接捆绑来源不明字体。

### 8.4 纹理、颗粒、发光
- 羊皮纸纹理极轻（局部透明度约 2–6%）；避免全屏泛黄。
- 颗粒缓慢漂浮，作为空间深度线索而非主角。
- 发光遵循亮度层级：主要实验 > 核心数据 > 历史注释 > 背景纹理。
- 需要有真实层次：前景刻度/微尘、中景实验、后景纹理与暗部。

### 8.5 运动语言
- 以慢推、缓旋、视差、精确路径生长为主；关键发现可用短促加速。
- 禁止所有元素统一淡入上移；每个转场必须由物体或概念关联驱动。
- 镜头转换：钟针→运动轨道→引力等势线→地球航线→卫星轨道→虹膜→神经/记忆碎片→钟针。
- 复杂曲线要先计算几何/物理数据，再逐帧呈现；不要随意手绘出“像科学”的错误曲线。

## 9. 无旁白的可读性规则
- 每个节点最多两组主要文字：历史锚点 + 结论；必要的标签可以少量补充。
- 每条中文结论尽量 ≤18 字，留出至少 3 秒有效阅读窗口；关键实验结论不在高速转场中显示。
- 观众静音观看仍能理解：每个实验必须有标尺、对照或明确标签。
- 科学准确性高于文案诗意；任何“时间变慢”都必须能辨认指物理还是感知。

## 10. 音效制作与混音
- **不导入参考片的音乐，不提取其音轨**；后期用户自己选择并合法使用配乐。
- 音效类型：机械钟、金属摩擦、轻纸张翻页、粒子掠过、低频空间氛围、飞机远鸣、定位扫描、眼球扫视、风压、心跳、记忆颗粒。
- SFX 应使用授权明确的素材或自行合成。每个声音写入 `assets/sfx/SOURCES.md`，记录来源、许可和用途。
- 导出 `final_sfx_only.mp4` 与 `sfx_stem.wav`，方便后期混入 BGM。
- 音效峰值避免削波，关键瞬间不过度轰鸣；尾声留出音乐空间。
- 建立逐镜头 SFX cue 表：帧号、音效文件、增益、淡入淡出、意图。

## 11. Remotion 技术架构
建议：TypeScript + React + Remotion，SVG 负责高精度图解，Canvas/Three.js 仅在确实需要粒子或 3D 场景时使用。所有随机行为固定 seed；所有动画基于 `useCurrentFrame()` 或可确定的时间函数，不允许依赖浏览器实时时钟。

```text
src/
  Root.tsx
  compositions/TimeIsNotUniform.tsx
  scenes/
    Opening.tsx
    Newton.tsx
    SpecialRelativity.tsx
    GeneralRelativity.tsx
    AtomicClocks.tsx
    GPS.tsx
    Chronostasis.tsx
    FreeFall.tsx
    Memory.tsx
    Ending.tsx
  components/
    DocumentaryYear.tsx
    HistoricalAnnotation.tsx
    ScientificClock.tsx
    GoldParticles.tsx
    ParchmentTexture.tsx
    CaptionLine.tsx
  simulation/
    clockPaths.ts
    orbitPaths.ts
    timelineMemory.ts
  config/
    scenes.ts
    theme.ts
    sfxCues.ts
  assets/
    textures/
    sfx/
    historical/
  docs/
    sources.md
    shotlist.md

```

- 使用 `<Sequence>`/`<Series>` 明确分镜时间；避免片段叠加造成字幕串场。
- 实验场景可抽离为可测试的纯函数：输入 frame / 参数 → 输出位置、时钟读数、状态。
- 视频生成不依赖外部 API 的在线调用；所有资源本地化并记录来源。
- 如历史照片不可合法使用，使用自制文献式示意图，并清楚标记为视觉演绎。

## 12. 开发流程与交付门禁
### Gate A：参考片研究
输出 `docs/reference-analysis.md`：参考片的 12 张代表性抽帧及其视觉规律。只用于内部研究，不打包发布受版权限制的参考素材。

### Gate B：先做 12 秒风格样片
只实现 00:00–00:12，验证字体、金属钟、纹理、暗金光效、运动与音效。**样片未达到纪录片质感前，不进入全片制作。**

### Gate C：节点 2 与节点 6 原型
先实现一个物理钟差镜头、一个主观停钟镜头，确认两种时间概念在画面上有清晰区别。

### Gate D：完整粗剪
完成全部 8 节点，先保证科学逻辑、视觉闭环、节奏连贯；暂不追求每一帧极致细节。

### Gate E：精修与验收
优化过渡、光影、颗粒、字幕排版、SFX；逐镜头抽帧；检查低端设备播放流畅性。

## 13. QA 验收清单
- [ ] 实际 MP4 为 1920×1080、30fps、16:9，时长与时间线一致。
- [ ] 只有 8 个知识节点，没有偷偷添加第九个核心理论。
- [ ] 无旁白、无内置最终 BGM，SFX 轨道独立可编辑。
- [ ] 前 5 秒有明显视觉悬念，前 12 秒建立完整风格。
- [ ] 每个节点能在静音下靠画面 + 极短文字理解。
- [ ] 历史年份、人名、实验数字、理论含义已核实，记录在 `docs/sources.md`。
- [ ] 物理走时差与主观错觉没有混为一谈。
- [ ] 没有网页卡片、扁平 PPT、赛博蓝紫色、过度炫光。
- [ ] 年份、历史注释、字幕、实验图形使用统一的视觉系统。
- [ ] 关键帧截图无裁切、乱码、溢出、闪烁、遮挡或莫名跳帧。
- [ ] 抽查片头、8 个节点中段、节点切换、片尾，共至少 20 帧。
- [ ] 所有外部素材与音效有来源记录及许可说明。
