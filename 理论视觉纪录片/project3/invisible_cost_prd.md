## 0. 接到任务后的执行命令（给开发智能体）

你正在制作一条 **140 秒、16:9 横屏、1920×1080、30fps、完全没有旁白** 的原创知识短片，名称为《看不见的代价》。用户同时会提供《运气的形状.mp4》作为**艺术方向参考**。

你必须：

1. **先观看参考片**：用 ffprobe 获取信息，用 ffmpeg 定间隔抽帧并制作接触表，检查其真实画面结构、构图、文字层级、粒子密度和运动节奏；如有条件检查静音下的转场与镜头；写出内部 `docs/reference-analysis.md`。不得声称分析了实际上没读到的内容。
2. **先出 12 秒样片**：选择“玻璃碎裂 → 六枚法郎 → 隐去的选择”这一段进行风格验证，生成可播放 `preview/style-proof.mp4` 和关键帧截图；若用户没有机会反馈，则按本 PRD 的验收标准自行检查后继续，不要中途停在等待确认。
3. **完整实现**全部镜头、说明文字、动效、真实可渲染的音效轨，不能只建立空组件或 TODO；最终导出完整 140 秒 MP4。
4. **保留音效、不加背景音乐、不加人声**；另外提供无声画面版和单独的音效 WAV，方便用户后期配上自己选择且已获授权的音乐。
5. **素材原创或合法取得**，不得直接复制参考片画面、贴原片截图、提取原片音乐或模仿其水印/署名。
6. **优先视觉质量与信息清晰度**。如果算力有限，减少次要粒子数量，也不能把核心实验降级成静态 PPT 或廉价的卡片平移。
7. 交付前对整片逐段抽帧、核对中文字幕、检查时间点与音画，并确认产出文件实际存在且可播放。

最终交付 `output/看不见的代价.mp4`、`output/看不见的代价_clean.mp4`、`output/看不见的代价_sfx.wav`，以及源码和素材来源文件。不要只交项目或渲染命令。

## 1. 作品定位与核心构想

### 1.1 定位

- **平台**：用户个人账号；与「如果放映局」账号及其“如果”系列**无关**，禁止加入「如果放映局」片头、水印、Logo 或系列口播。
- **艺术类型**：经济学思想 × 历史文本 × 抽象动态图形 × 视觉寓言。
- **知识数量**：**三个核心概念**，不硬塞更多：①机会成本；②当下偏好；③沉没成本效应。巴斯夏的破窗寓言负责引入第一概念，**不是第四个额外定律**。
- **观看方式**：不使用旁白；以镜头内直观变化为主，少量短字承担必要语义；音乐由用户后期自行配。
- **思想起点**：人在做选择时，往往只看到“得到了什么”或“付出了多少钱”，较难看见没有发生的其他可能。
- **叙事主角**：**一枚金币 / 六枚法郎 → 一道选择分叉 → 一座天平 → 一张剧院季票 → 一枚金币**。

### 1.2 一句话梗概

> 1850 年的一块破窗，让一枚金币走向两种互斥的用途；镜头追随那些未被选中的道路，从经济学的机会成本进入人对未来的低估，再进入不愿放下过去投入的困境；最后回到金币，发现真正的代价有时根本不会出现在账单上。

### 1.3 观众看完应理解的三句话

1. **机会成本**：选择某一用途时，会放弃其他用途中最有价值的一种。它不等于把所有没选的好处相加。
2. **当下偏好**：人在某些跨期选择中会对“立即得到”赋予额外权重，偏好可能随时间接近而改变；这不是所有人的固定反应。
3. **沉没成本效应**：已经付出、无法收回的成本，有时会不恰当地影响下一步决定；是否继续，重点应看**此后**的收益和成本。

### 1.4 成功标准（严格）

- **静音看得懂**：关闭全部音轨，至少能看出“钱的两种用途—一条路消失—远近奖励的权衡—季票已经付费仍继续出席—回到选择”五段故事。
- **只看三张关键帧有统一美术**：暗金粒子、深黑空间、羊皮纸、精细线条和历史注释相互一致。
- **不是视频版论文，也不是 PPT**：概念随物体运动自然出现；画面中实际发生事件，而非文字列表依次弹入。
- **情绪克制**：引人沉思，但不责备观众，也不暗示休息、娱乐等选择必然错误。

## 2. 参考片《运气的形状》：保留什么，避开什么

### 2.1 必须借鉴的“视觉语法”

参考片的可识别要素包括：

- 近乎纯黑的空间，局部暖金照明、低密度浮尘；
- 左上精炼年份和人物/地点信息，右上短文献名或备注；
- 视觉核心集中在画面中部——骰子、实验物体、统计结果等；
- 下缘简短而有节奏的中文说明，文字量远少于常规知识解说；
- 不时出现羊皮纸卡、古典手稿、旧时代科学图解，但从不把整个画面塞满纸纹；
- 物体与数据**发生真实的变化**，例如骰子出现、路径分叉、分布逐渐形成；
- 黑暗中的金色高光作为视线锚点，暖色与暗红/旧铜少量区别不同路径或结果；
- 慢推、弧形绕拍、局部停顿、精密机械声与颗粒声服务于知识的出现。

### 2.2 明确禁止的照搬行为

- 禁止截取/改色/去水印后使用参考片任一画面；
- 禁止复制参考片具体片头图案、排版像素坐标、原字幕、Logo、水印；
- 禁止提取其中音乐当作素材，也不要让 AI 擅自用相似旋律拼接替代；
- 禁止做成同一个视频改文案；只借鉴**美术系统、知识演示方法和克制节奏**。

### 2.3 本片的独特核心物体

**金币**必须成为所有场景的视觉连续性基因，具备如下固定特征：

- 古典旧金色材质，浅浮雕内圈，边缘有细密齿纹；
- 主要反光来自画面上方偏左约 35° 的柔和点光源；
- 采用一致的简化钱币纹饰，**不声称复刻 1850 年真实法郎币制**；
- 钱币可以变为时钟、分叉道路、票券凹印或记忆光点，但观众能认出是同一种视觉语言。

## 4. 美术指导：黑金羊皮纸的“历史经济学纪录片”

### 4.1 设计令牌

| 用途 | 颜色 | 使用方式 |
|---|---|---|
| 近黑背景 | `#090908` | 占 75%+，带轻微暖黑渐晕 |
| 石墨黑 | `#13110F` | 局部三维层次、暗部轮廓 |
| 暗金主色 | `#C49A57` | 重要物体、年号、实验轨迹 |
| 边缘亮金 | `#E8CA88` | 唯一视觉中心的高光，面积极小 |
| 羊皮纸 | `#E8D6B1` | 说明文字、文献页、少量粒子 |
| 旧铜色 | `#826142` | 低权重图线、历史注释、阴影 |
| 灰金 | `#9B8A70` | 次级说明与刻度 |
| 枯红棕 | `#763E32` | 仅表示失去、取消、沉没成本；非常少 |

**不能使用**荧光青、炫紫、科技蓝霓虹、霓虹 HUD 面板、通用企业仪表盘渐变、直播风爆炸转场。

### 4.2 背景的正确做法

- 主背景为 `#090908`；叠加半径大、强度低的暖金径向光与轻微不规则材质，不是纯黑一整片；
- 细微浮尘密度：参考 1920×1080 可见同时约 20–60 个，随机位置由固定种子确定；
- 胶片颗粒低幅度且轻微动态，**不许**看上去脏、糊或有抖动噪点；
- 暗角极轻；重要文字区域必须确保对比；
- 羊皮纸**只在文献、账页、档案卡**出现，并有不规则边缘与纤维纹理；不用整屏米黄色。

### 4.3 字体和排版

- 中文字幕与片名：优先本地可合法使用的高品质宋体（例如思源宋体 Noto Serif CJK SC）；字形须稳重，笔画不能过细以免视频压缩模糊；
- 英文、小年份与文献：Noto Serif / Libre Baskerville / Georgia 等有文献感的衬线字体；
- 辅助数据：具有稳定数字宽度的衬线/等宽数字，金额、小数不跳动；
- 无网络字体运行依赖：字体许可须核对，允许本地打包但**不分发专有受限字体**；
- 片名中文约 92–118 px；章节题 48–64 px；说明文字 34–43 px；角落历史注记 18–26 px（1920×1080 基准）；
- 主要说明最多两行，每行建议不超过 20 个汉字；单次说明一般停留 3–5 秒；
- 字幕位于画面底部偏上安全区域，基线建议 `y≈936`，画面左右安全边距 ≥ 110px、底部 ≥ 95px；
- **不要原样复刻参考视频的角标像素位置**；采用类似的信息等级，但建立原创版式。

### 4.4 参考片式信息布局

```
┌──────────────────────────────────────────────────────────────┐
│  1850                                  法文文献 / 经济学手稿   │
│  Frédéric Bastiat                     三行以内细小档案字注    │
│                                                              │
│                                                              │
│                    核心实验与主视觉对象                     │
│                  金币 / 玻璃 / 路径 / 天平                   │
│                                                              │
│                                                              │
│                                                              │
│               人们看见了修好的窗户。                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

画面焦点应主要落在中部 65% 区域；左上/右上角始终让位于中央主视觉。**信息文字是文物标签，不是软件 UI。**

### 4.5 光学与动画质感

- 物体材质：磨砂金属 + 少量边缘高光；避免廉价塑料金币；
- 光照：柔和主光、极弱补光，金属反射动态随物体旋转产生，背景不盲目发亮；
- 镜头：缓慢 dolly-in、轻 orbit、镜头焦点转移；景深适度，不可让文字虚焦；
- 运动节奏：多使用 ease in-out 与真实缓入缓出，弹性动画只用于物理合理的撞击反弹；
- 粒子数量应服务意义，不能开场全程“粒子乱飘”；
- 转场遵循“一个物体形态延续”原则，不采用大量纯遮罩剪切；
- **每 5 秒至少发生一个肉眼可辨的视觉变化**，但不能靠胡乱抖动假装有运动。

## 5. 理论、史实与叙事边界（必须准确）

### 5.1 历史故事：巴斯夏的破窗（1850）

- 史实基础：Frédéric Bastiat 于 1850 年发表的《Ce qu’on voit et ce qu’on ne voit pas》（《看得见的与看不见的》）包含著名“破窗”寓言；
- 原故事的修理费用是假设的 **六法郎**；破窗使玻璃工获得工作，但屋主这笔钱无法再用于**鞋子或书等其他用途**；
- **选择一个具体替代品作画：鞋子。**不要同时把鞋子和书都算作“失去的六法郎”，避免重复计算；
- 核心结论：修窗的支出确实可见，但把损失本身当作整体经济收益，会忽略未发生的其他用途与原本被破坏的资产；
- **不可以**把“破窗是好事，能创造财富”作为结论；
- 片中金币是抽象代币；史实单位写“6 法郎”，不必声称画中的币型是历史还原。

### 5.2 概念一：机会成本

- 定义：给定一个选择，被放弃的最佳可行替代机会的价值（并非所有选项价值之和）；
- 用同一笔钱两种互斥去向讲清楚；延展到“时间只能花一次”；
- 不能暗示“休息必然比学习差”或“花钱一定是错误”。不做价值审判。

### 5.3 概念二：当下偏好（Present Bias）

- 用两个选择画面解释“**现在**”的额外吸引力；
- 可以展示示意性的偏好翻转：A. `现在 1 枚` 与 `7 天后 2 枚`；B. `30 天后 1 枚` 与 `37 天后 2 枚`；
- 画面标题须注明“**示意选择**”，**不能**暗示做了真实真人实验、不能声称所有人必选某项；
- 辨析：对未来的正常折现与当下额外偏好不是同一回事；无需播放公式，只用视觉强调“今天”和“将来”的权重变化；
- 1997 年 Laibson 的双曲贴现研究可作为右上文献小注，但不能让观众误以为现象首次于该年发现。

### 5.4 概念三：沉没成本效应（Sunk Cost Effect）

- 1985 年 Arkes 与 Blumer 发表研究，在一项剧院季票现场研究中，初始支付较多的观众在随后的部分时期出席更多场演出；
- 用**季票、多场戏、已付费用、未来出席决策**表现，而不是“一张单场门票=1985研究的复刻”；
- 不虚构研究中的具体样本量、价格、出席次数或统计显著性数字；如必须使用演示数字，标明“示意 / 非论文原数据”；
- 关键是已无法收回的票价与**接下来仍要付出的时间和精力**的区分；
- 结论不应是“买了季票就不该去看戏”：如果未来观看值得，它仍然可以是理性选择；避免绝对化。

### 5.5 术语禁区

- 不以“沉没成本定律”代替“沉没成本效应”；
- 不把每一种取舍都画成“选择即失败”；
- 不将巴斯夏、机会成本、当下偏好、沉没成本效应说成单一理论的四个阶段；它们是一个主题串联的不同分析角度；
- 不把所有非选路径的金额相加当作“机会成本”。

## 6. 总体故事节奏与章节分布

**全片 140.0 秒 / 4200 帧。** 章节均有起承转合，使用视觉物件连续演化。

### 7.1 字幕管理

- 上述 28 条台词中有明确“（无）”场景，不能擅自加文案；
- 片名为《看不见的代价》，至少 S04 出现；S28 可在顶部或后方隐约重复；
- 不使用“请关注”“点赞”“收藏”或“下一期见”；
- 如果过渡时间导致阅读困难，优先微调字幕出现的具体帧与停留时间，不允许删掉关键知识定义；
- 所有关键中文必须真实渲染，不能把中文交由文生图模型生成（容易乱码）。

### 7.2 章节右上文献注记（必须克制）

- **1850**：`Frédéric Bastiat · Ce qu'on voit et ce qu'on ne voit pas`；
- **机会成本**：`OPPORTUNITY COST · CHOICE & ALTERNATIVES`，无需伪造发明年份；
- **当下偏好**：`PRESENT BIAS · INTERTEMPORAL CHOICE`；可小字注明 `D. Laibson · 1997`，仅为研究参考；
- **1985**：`H. R. Arkes & C. Blumer · The Psychology of Sunk Cost`。

所有文献小字要用正确字体、正确拼写；读不清的微小字宁可删掉，也不能做假的“科研感乱码”。

## 8. 四段最重要的动画逻辑（禁止只做结果图）

### 8.1 A：碎玻璃转六法郎

**输入**：玻璃片轮廓（多边形 mesh）、撞击点、碎裂图、6 个钱币目标轨迹。  
**过程**：

1. 先展示完整玻璃表面的微弱光泽；
2. 撞击扩散的裂痕沿固定的几条分支向外生长；
3. 小碎片按固定种子取得不同速度和角速度，拖尾迅速减弱；
4. 选取 6 组主要碎片汇聚成 6 个圆形光晕，生成 6 枚金币；其他碎片逐渐化尘；
5. 最终 6 枚金币移到窗口修补的支付路径；
6. 视觉上金币流出意味着一种经济用途发生；后续必须展示对应“没能发生”的替代用途。

**验收**：S02 最少存在 1 次完整的“裂痕扩展→物理散开”过程，S03 观众能认出“玻璃→金币”连续转化；S06 明确出现 6 枚。

### 8.2 B：破窗两种反事实对照

数据结构建议：

```ts
const brokenWindow = {
  repairCostFrancs: 6,
  actual: {window: "repaired", shoes: false},
  alternative: {window: "intact", shoes: true},
};
```

- 左场景：玻璃先坏，再修好；钱交给玻璃匠；最终有窗但没有新鞋；
- 右场景：玻璃从未损坏；屋主把同一笔钱用于鞋子；最终有窗也有鞋；
- 用“实线”表示发生的路径，用“虚线/半透明”表示反事实分支；
- 不允许两个世界出现两倍的钱；不允许通过视觉暗示修窗产生了新的净财富；
- **无法实际知道屋主会买鞋**：视频需以“假如这笔钱用于鞋子”表现为可行替代，不能说一定会买。

### 8.3 C：一小时三条路径

**不是把三个选项画成 web 卡片。** 

- 时钟外圈生出三条线段，细线分别通往工作、休息、学习的抽象雕刻物；
- 选择脉冲只沿一路前进；未选路线**先保留形状一瞬**，让观众意识到它们原本存在，然后逐渐隐去；
- 第 14 镜以“最好的一条未选路”为唯一主要机会成本；其他路径安静退背景；
- 不给工作、休息、学习预设固定数值排名，避免武断。可通过标签“假设在此情境中，这条未选路最有价值”表达；
- 三条路径只是一组**示意选择**，不是人生应做决定的建议。

### 8.4 D：当下偏好的时间平移

用真实数字与两个时点保持条件一致：

```ts
const intertemporalPairs = [
  {left: {coins: 1, days: 0}, right: {coins: 2, days: 7}},
  {left: {coins: 1, days: 30}, right: {coins: 2, days: 37}},
];
```

- 两组比较的奖励相同、间隔同为 7 天，区别只是整体平移 30 天；
- 只以金光权重演示**一种可能的偏好翻转**，不是模拟真实人群统计；
- 在角落常驻 `示意选择`，不要放有虚假比例的柱状图；
- 远期奖励缩小是视觉隐喻，结尾应恢复原本客观数量，明确“价值感觉变了”而不是“金币少了”。

### 8.5 E：剧院季票与沉没成本

- 季票统一一张贯穿多场演出的票根，切勿误用单次门票直接代表现场研究；
- 高价和低价组区别可以用票面边框厚度、金币投入动画，不允许直接标注原研究未核实的数字；
- “多场演出”的场景要用可见的节目单/日历翻动/舞台换景表达；
- 之后单独出现两本账：过去已付 `不可追回`、未来进场需要投入 `时间/精力`；
- 未来选择本身保持开放，不用“走出剧院就赢了”之类评价。

## 9. 声音设计：只有 SFX，无 BGM / 无人声

### 9.1 交付策略

- `看不见的代价.mp4`：原始 SFX 在片中的位置已经配置好；
- `看不见的代价_clean.mp4`：不含任何音轨或为完全静音画面；
- `看不见的代价_sfx.wav`：从 0 秒开始、长度与成片精确一致的 48 kHz stereo PCM 音效轨；
- **不放临时背景歌曲、不合成所谓“相似的那首 BGM”**。后期用户自行叠加已获使用许可的音乐；
- SFX 留有动态余量：建议 SFX 总峰值不高于 -9 dBFS，避免与未来配乐相加削波。必要时用 limiter，但不可过度压缩。

### 9.3 技术规则

- `sfxEvents` 独立配置文件，字段包含 `file`, `startFrame`, `durationFrames`, `volume`, `fadeInFrames`, `fadeOutFrames`；
- 所有音效资源须实际存在、路径正确、合法可使用；不允许引用不存在的文件；
- 禁止把整段参考视频声音直接作为“音效素材”；
- 优先使用自主合成的短 SFX（简单鼓点/滤波噪声/正弦金属泛音）或合法授权的环境/拟音音频；
- 自动渲染时任何缺失的音频文件必须报错并补齐，不能悄悄不出声。

## 10. Remotion 技术设计

### 10.1 推荐技术组成

- **Remotion + React + TypeScript**：视频时间线、合成、字幕与整体渲染；
- **SVG**：精确线描、分岔路径、金币浮雕纹饰、文字下划线、年份出现；
- **Canvas / 预烘焙粒子轨迹**：玻璃碎片、灰尘、金光轨迹、沙化；
- **Three.js / R3F 可选**：仅用于硬币的近景材质与一两个真实 3D hero shot；复杂 WebGL 渲染如在无头 Chromium 不稳定应及时降级到预渲染透明片段；
- **FFmpeg**：检查参考素材、导出与核验多音轨；
- 所有动画以 Remotion 当前 frame 为输入，确保每帧可重复再现。

### 10.2 渲染确定性（非常重要）

- 不可在 `render()` 中使用不带种子的 `Math.random()`；
- 不使用随实际时间推进的 `Date.now()`、CSS 无限动画、`setTimeout` 或外部网络数据；
- 函数形如 `renderState = simulate(frame, seed, config)`；
- 同一帧在不同机器与不同并行渲染序下须得到同一图像；
- 物理碎片可预计算位置数组，也可固定步长解析计算；
- 所有过渡用 `interpolate`, `spring` 等 frame-based 接口，不允许组件 mount 时动态触发。

### 10.5 字幕效果

- 说明文字轻微字距变化、局部金粉凝聚或遮罩显现；
- **禁止逐字打字机速度过慢**（无旁白，需要观众足够时间阅读）；
- 中文绝不使用生成式图片文字，统一真实字体渲染；
- 不使用彩色描边/强投影等短视频常见字幕特效；
- 可让关键名词如“6 法郎”“机会成本”“未来”局部暖金，其余使用羊皮纸文字。

### 10.6 性能与降级

- 以 1920×1080 30fps 为终版目标；如调试缓慢，开发阶段可 960×540 / 15fps 检查，但**不可当作终交付**；
- 复杂粒子优先预计算缓存，必要时使用在时间线上透明叠加的独立渲染片段；
- 同一画面动态粒子建议 100–800 量级，必要时减少，不追求无意义的十万粒子；
- 保证文字与主要物体的边缘稳定，无明显锯齿；
- 镜头模糊、运动模糊要节制，不影响阅读；
- 禁止任何“资源未加载”闪烁或 WebGL 黑屏帧。

## 11. 开发阶段计划与真实交付门槛

### Phase 0：文件检查与参考分析

- 找到当前工作目录中的《运气的形状.mp4》；不可以拿不到就凭空声称已经看完；

**门槛**：参考确实看过，资料确实读过；暂时不允许用空模板代替。

### Phase 1：12 秒美术样片

优先制作 S02→S03→S04→S05 的连续视觉（可以从原片 4 秒开始重新计时做 12 秒 proof），必须出现：

- 玻璃真实裂解与转为 6 枚金币；
- 正确黑金色和局部光；
- 羊皮纸质感而非普通浅色矩形；
- 片名排版；
- 两种以上层次的合理 SFX。

**门槛**：`style-proof.mp4` 真实存在，可播放，可截图；字体无错误；风格不像现代 UI 宣传片。

### Phase 2：核心实验动画

- 先完成破窗对照 S05–S10；再做分叉路 S11–S15；然后天平 S16–S20；最后剧院 S21–S25；
- 每个实验建立可复现数据模型与相应说明文字；
- 实现片头与片尾共用的金币视觉组件。

**门槛**：四个实验都能在静音下看出因果变化；不能用“两个静止画面淡入淡出”假装实验过程。

### Phase 3：全片剪辑 / SFX

- 实现 S01–S28 的精确时长与镜头转场；
- 完成音效事件时间线；
- 导出三种声音规格；
- 添加原创封面图与片尾留白。

**门槛**：140 秒、无 BGM、无旁白、SFX 轨齐全。

### Phase 4：质量检查与最终渲染

- 使用 ffprobe 确认规格、时长、编码、音轨；

- 检查音效峰值与后期音乐余量；
- 最终导出三个视频/音轨 + 封面 + 简洁 README。

**门槛**：全部输出在文件系统中实际存在；一条能在普通播放器里观看的最终 MP4，而不是“理论上可渲染”。

## 12. 验收清单（逐项检查）

### 12.1 内容正确性

- [ ] 仅 3 个核心概念：机会成本 / 当下偏好 / 沉没成本效应。

- [ ] 当下偏好示意不假装真实社会统计；奖励金额与时间间隔前后保持一致。
- [ ] 1985 研究表现为**季票及多次演出**，不乱填精确统计数。
- [ ] 结尾不指责休息、学习、工作或娱乐任何一种行为。

- [ ] 整片基调深黑、暗金、羊皮纸色。
- [ ] 片头 8 秒内出现高质量视觉事件，不能是长时间黑屏。
- [ ] 金币、玻璃、时钟、天平、票券至少五种对象有连续变形或动态演示。
- [ ] 年份、文献与实验说明的字体和颜色统一。
- [ ] 字幕简短、中文清晰、没有假古文乱码。
- [ ] 没有科技蓝 HUD、网页卡片、商单式宣传画面、廉价金色镭射粒子。

### 12.3 工程与成片

- [ ] 工程可用固定命令安装、预览、渲染。
- [ ] 总帧数 `4200`；宽高 `1920×1080`；`30fps`。
