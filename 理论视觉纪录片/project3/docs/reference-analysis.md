# 参考片《运气的形状》美术分析（内部）

> 仅作艺术方向参考。参考片画面、音乐、字幕、水印均**不进入**本片时间线。

## 1. 技术信息（ffprobe 实测）

| 项 | 值 |
|---|---|
| 文件 | `../infomation/参考视频/运气的形状.mp4` |
| 时长 | 133.03 s |
| 视频 | H.264，1280×720，30 fps，yuv420p，约 909 kb/s |
| 音频 | AAC 44.1 kHz 立体声，128 kb/s |
| 音频响度（实测，每秒 RMS） | 全程约 −6 至 −14 dBFS，峰值约 −0.1 dBFS。整片铺满音乐，几乎没有安静段落。本片按 PRD 只做 SFX，响度要低得多，给后期配乐留出余量 |

## 2. 方法

- 每 3 秒抽一帧（0–132 s，共 45 帧），用 `scripts/contact_sheet.py` 拼成接触表：`docs/ref-frames/sheetA.jpg`（0–57 s）、`sheetB.jpg`（60–132 s）。
- 全分辨率检查了 20 s（1494 帕乔利赌注）和 77 s（伯努利罐子）两帧，并用 numpy 统计了这两帧的色彩。
- 所用 Remotion 自带的 ffmpeg 没有 `fps`/`tile`/`select` 滤镜，所以改为按时间点逐帧 `-ss` 抽取，再用 PIL 拼接。镜头切换的判断来自这些 3 秒间隔的抽帧，**没有逐帧检查**。

## 3. 观察结果

### 3.1 色彩
- 背景几乎全黑，但不是纯黑。20 s 那帧的中位像素是 RGB(20,14,9)，偏暖棕黑；77 s 那帧是 RGB(10,10,13)，略偏冷的蓝黑。可见后半段会在暖黑和冷黑之间切换。
- 高光（第 99 百分位）约为 RGB(218,185,148)，是羊皮纸/暗金一类的颜色，不是饱和的黄色。
- 一般用金色表示主体，用砖红色表示对立的一方或“中断”（如“乙”方的进度条、红色印章）。红色面积非常小。
- 画面中心常有一大片低强度的暖色径向光，四角压暗。

### 3.2 版式与文字层级
- **左上**：年份大字（约占画高 6–7%，衬线，金色），下方一条细分隔线，再接一行小字写地点和人物（如“威尼斯 · 帕乔利”）。
- **右上**：拉丁文斜体书名 + 中文书名号书名 + 作者·地点·年份小字，旁边有一个小红印“文献”。三行以内，右对齐。
- **底部居中偏左**：一行宋体粗字说明（约占画高 4.5%），羊皮纸白色，关键词局部用金色（如“未来”“15 : 1”“π”）。入场方式是从左到右的模糊→清晰扫入（20 s 那帧正好拍到扫入途中）。
- 画面中部偶尔有一行小字副题（如“先到 60 分者，赢走全部赌注”），字距很宽。
- 片名卡：中文大字带金属渐变和柔光；上方有拉丁小字 “DE FORMA FORTUNAE”，字距极宽；下方是一条正态曲线细线、一行副题和出品信息。
- 抖音水印、账号号码和片尾抖音页面属于平台叠加物，**不借鉴**。

### 3.3 主视觉
- 每一段都有一个视觉核心，放在中部 60% 的区域：骰子、命运之轮、赌注金币、6 面展开图、骰子组合阵列、分岔树、伦敦账单墙、黄金粒子、罐子+收敛曲线、二项柱状图、布丰投针、高尔顿板、公理列表。
- 很多镜头是**过程演示**：分岔树路径逐条亮起，红色高亮的路径代表乙方获胜；投针计数在增加；高尔顿板上珠子落下、逐渐堆出正态分布；伯努利曲线在收敛。
- 线条很细（约 1–1.5 px，720p 下），用暗金色；节点是小亮点；用了大量细刻度和小号注记。
- 羊皮纸只出现在账单墙（69 s）和少量卡片上，从不铺满整屏。
- 粒子：前景浮尘稀疏（每帧可见约十几到三十几颗，大小不一，部分虚焦）；只有 72 s“整座城的数字”那一处用了密集金色粒子云。

### 3.4 节奏
- 每条说明大约 3–5 秒，帧与帧之间几乎总有变化。
- 年份切换用滚动数字（27 s 的 “1534”、75 s 的 “1701→1713”、114 s 的 “1910” 都拍到了滚动中的数字）。
- 片头：黑场 → 骰子出现 → 骰子展开成概率刻度 → 片名（约 9 s）。片尾回到同一颗骰子，然后片名重现，形成首尾呼应。

## 4. 本片如何借鉴，如何避开

| 借鉴的语法 | 本片的原创实现 |
|---|---|
| 左上“年份 + 细线 + 人物”的档案标签 | 用自己的版式：年份配一条渐隐的金色细线，章节序号用“壹/贰/叁/肆”。位置和字号都是独立设计的，没有照搬像素坐标 |
| 右上文献注记 + 小印 | 文献只写 PRD 7.2 规定的内容；小印改用旧铜色的方形线框，印文为“文献”或“示意” |
| 底部扫入式说明，关键词金色 | 基线在 y≈936，带遮罩扫入 + 轻微字距收拢；每条说明都有退出动画 |
| 过程演示：分岔、收敛、累积 | 玻璃碎片→六枚金币、反事实账本、三岔路熄灭、天平+时间平移、季票多场演出 |
| 首尾同物呼应（骰子） | 本片的视觉母体是**金币**，币面浮雕是原创的拱窗纹样 |
| 片名卡：金属渐变中文 + 宽字距拉丁副题 | 片名为“看不见的代价”，拉丁副题用 Bastiat 原题 “CE QU'ON NE VOIT PAS”，下方的细线改成精密刻度和分岔线，没有使用正态曲线 |

**明确不借鉴**：参考片的任何画面、骰子模型、命运之轮、高尔顿板、配乐、抖音水印和账号信息、“Iwanau 出品”式署名，以及具体的版面坐标。
