# 理论视觉纪录片｜Remotion 选题库

> **版本**：v1.0 · 2026-10-28  
> **定位**：独立于「如果放映局」的生活脑洞动画，用个人账号发布的理论视觉纪录片。  
> **参考风格**：用户提供的《运气的形状》——**深黑、暗金、羊皮纸色；历史科学纪录片气质；年份、文献、人物、实验图形、发光粒子统一设计**。借鉴语言，不照搬具体画面、素材或音乐。

## 使用说明

- **固定编号 T01～T20**。以后直接发「讨论 T07」或「给 T14 做一份 Remotion PRD」，就能按编号继续。
- 下面的理论是**备选素材池**，不代表每条必须全部讲到；正式制作时应精简为 3～8 个真正相关的知识节点，严格核查科学准确性。
- 评级是**主观创作评估**，不是对播放量的预测。难度是开发难度（低／中／高），不是理解难度。
- 默认制作方向：**1920×1080、16:9 横屏、30fps、无旁白、少量解释文字**；Remotion 负责场景、动态图形和音效。背景音乐由用户后期自行加入，并自行确认使用授权。
- 本库与「生活脑洞动画」的 **01～30** 选题库分开管理，不混用编号。

## 02｜选题详情

### T01｜时间并不均匀
- **一句话概念**：一秒钟真的对每个时钟、每个人都相同吗？
- **知识素材**：牛顿绝对时间观、狭义与广义相对论、环球原子钟实验、GPS 时间校正、停钟错觉、危险情境中的时间知觉、事件分段与回溯性记忆。
- **视觉主线**：同步时钟 → 不同运动与引力下的时钟偏差 → 大脑里的主观时钟 → 记忆时间轴。
- **高潮镜头**：数百只钟原本完全同步，最后沿不同路径出现不同读数；三种“时间”通过连贯视觉转场连接。
- **科学边界**：物理时钟的走时差异、主观时间感受、回顾时长判断不可混为同一种机制。
- **状态**：已有 PRD；后续可迭代分镜和镜头资产。

### T02｜看不见的代价
- **一句话概念**：我们看见付出去的东西，却很少看见因此消失的另一种可能。
- **知识素材**：巴斯夏的“破窗”故事、机会成本、当下偏好、沉没成本效应。
- **视觉主线**：破碎玻璃 → 6 法郎金币 → 被放弃的购买选择 → 眼前与未来的天平 → 已付款的剧院门票。
- **高潮镜头**：一枚金币分叉出多条道路，选中一条后其他路径慢慢化为暗金尘埃。
- **科学边界**：机会成本通常指放弃的最佳可行替代方案的价值，不是所有未选方案的价值之和；沉没成本不能再通过当前决定追回。
- **状态**：已有 PRD；后续可迭代分镜和镜头资产。

### T03｜秩序，从混沌中诞生
- **一句话概念**：没有指挥者，简单的规则如何生出复杂的图案？
- **知识素材**：康威生命游戏、元胞自动机、涌现、自组织与复杂系统（概念关系需严谨）。
- **视觉主线**：几枚发光方格 → 按规则繁衍与消亡 → 滑翔机、振荡器、复杂结构 → 从微观网格拉远。
- **高潮镜头**：一整片黑金网格在固定规则下运行，出现复杂且有秩序的移动图案。
- **科学边界**：生命游戏属于确定性规则的元胞自动机，不应把它描述为纯随机过程；“混沌”在片名里是文学修辞，不等于数学混沌理论。
- **状态**：待讨论。

### T04｜世界的临界点
- **一句话概念**：为什么一些微小变化，会让整个系统突然换一种状态？
- **知识素材**：相变、渗流、临界阈值、网络级联故障（注意每种模型的具体条件）。
- **视觉主线**：水与冰的形态变化 → 稀疏网络中的孤立节点 → 跨过连接阈值 → 巨型连通结构出现。
- **高潮镜头**：几万个发光节点按模拟规则逐步连接，临界附近整体连通性显著改变。
- **科学边界**：不能声称所有复杂系统都存在相同的临界点或必然突然崩塌。
- **状态**：待讨论。

### T05｜无限的房间
- **一句话概念**：一个已经客满的旅馆，为什么还能迎接更多客人？
- **知识素材**：希尔伯特旅馆、可数无穷、无限集合一一对应、康托尔集合论。
- **视觉主线**：无限延伸的古典走廊 → 房间全部占满 → 全员从 n 号移至 n+1 号 → 再演示无限新客人如何安置。
- **高潮镜头**：编号像星光一样向无穷远连续移动，前方显露空出的房门。
- **科学边界**：是抽象数学思想实验，不是物理上可建造的旅馆；避免错误地把有限画面当成无穷的严格证明。
- **状态**：待讨论。

### T06｜财富有引力
- **一句话概念**：当优势可以积累，资源可能怎样逐渐集中？
- **知识素材**：累积优势、优先连接、复利、财富分布与不平等指标（按所选模型取舍）。
- **视觉主线**：所有人金币相同 → 按预设规则交易/获益 → 粒子分布逐渐偏斜 → 修改机制进行对照。
- **高潮镜头**：一整片金币光点向几个节点汇聚，而背景人群的分布曲线持续变化。
- **科学边界**：模拟结果取决于规则；不能将其宣称为现实财富差异的单一原因。
- **状态**：待讨论。

### T07｜混沌的边界
- **一句话概念**：即使世界遵循确定规则，为什么长期预测仍可能失效？
- **知识素材**：洛伦兹系统、初始条件敏感性、确定性混沌、预测误差增长。
- **视觉主线**：两条几乎重叠的初始轨迹 → 持续演化 → 轨迹逐渐分离 → 蝴蝶形吸引子。
- **高潮镜头**：两条细金线从几乎相同的位置出发，最后形成差异显著的复杂空间轨迹。
- **科学边界**：确定性混沌不等于随机；“蝴蝶效应”不应被解释为任何微小动作都会引发任意巨大后果。
- **状态**：待讨论。

### T08｜数字会说谎吗？
- **一句话概念**：同一份数据，为什么分开看与合起来看会得到相反结论？
- **知识素材**：辛普森悖论、统计混杂、选择偏差、均值误导。
- **视觉主线**：两组分层实验数据 → 各自都领先 → 合并样本 → 总体排名翻转 → 展示隐藏的样本比例。
- **高潮镜头**：两组黄金柱状图先后领先，随后数据方块重排，合并时排名当场反转。
- **科学边界**：必须使用可核算且自洽的示例数字；解释变化由分层权重/混杂因素造成，并非统计学自相矛盾。
- **状态**：待讨论。

### T09｜一座城市的呼吸
- **一句话概念**：道路增加了，为什么城市有时反而更堵？
- **知识素材**：排队论、交通网络、纳什均衡、布雷斯悖论。
- **视觉主线**：城市道路逐渐点亮 → 车流寻找最快路径 → 新道路开放 → 全体路线选择变化 → 总体延误上升。
- **高潮镜头**：黑金微缩城市中的车流像血液穿行，新桥亮起后，通行速度却整体下降。
- **科学边界**：布雷斯悖论发生在特定网络与选择条件下，不是“修路必然更堵”。
- **状态**：待讨论。

### T10｜孤独的数学
- **一句话概念**：每个人都只认识有限的人，为什么整个世界却紧密相连？
- **知识素材**：图论、友谊悖论、小世界网络、六度分隔的研究背景。
- **视觉主线**：零散小点 → 连接形成局部圈子 → 少数枢纽节点出现 → 镜头拉远形成大网络。
- **高潮镜头**：几千个微弱光点之间迅速浮现连接线，形成发光的人际关系宇宙。
- **科学边界**：六度分隔不是所有人任意两点都固定恰好六步；友谊悖论涉及平均与网络结构。
- **状态**：待讨论。

### T11｜记忆会撒谎
- **一句话概念**：记忆不是录像，回忆的过程也可能改变它。
- **知识素材**：重构性记忆、错误记忆、来源监控、遗忘曲线（按叙事需要选择）。
- **视觉主线**：古典照片被定格 → 一次次回忆 → 细节发生偏差 → 多段回忆重新组合。
- **高潮镜头**：同一个场景不断以金色线稿重建，某些细节在观众眼前悄悄被替换。
- **科学边界**：不要暗示全部记忆都是假的；不同研究范式的结果不能简单合并。
- **状态**：待讨论。

### T12｜随机的艺术
- **一句话概念**：没有预先画好的图案，随机运动能创造什么？
- **知识素材**：随机游走、布朗运动、扩散、分形（需分别明确机制）。
- **视觉主线**：一粒光点随机运动 → 十万粒轨迹叠加 → 扩散云显现 → 分形图案衔接。
- **高潮镜头**：细小的金色轨迹不断堆叠，在黑暗中形成复杂而优雅的统计形状。
- **科学边界**：不是任何随机过程都会自动形成分形；每幕标注对应模型。
- **状态**：待讨论。

### T13｜永远到不了的终点
- **一句话概念**：如果每次只走剩余距离的一半，我们究竟能不能到终点？
- **知识素材**：芝诺二分悖论、无穷级数、数学极限、微积分的历史发展。
- **视觉主线**：古典长廊 → 行者不断跨过剩余距离一半 → 分段越来越密 → 总距离收敛。
- **高潮镜头**：无穷细分的金线逐渐汇成一条完整路径，行者确实到达终点。
- **科学边界**：无限多个越来越短的时间间隔可以有有限总和，不能误讲成“现实中运动不可能”。
- **状态**：待讨论。

### T14｜合作与背叛
- **一句话概念**：在不断重复的博弈里，善意和背叛谁更有优势？
- **知识素材**：囚徒困境、重复博弈、以牙还牙策略、演化博弈。
- **视觉主线**：两个匿名参与者做选择 → 收益计数 → 扩大为数千人的策略竞争 → 不同环境下结果变化。
- **高潮镜头**：金铜两色阵营在博弈网格上不断相遇、交换、扩展与收缩。
- **科学边界**：结果依赖收益矩阵、互动次数、策略组成和演化规则；不能断言“合作永远获胜”。
- **状态**：待讨论。

### T15｜当人群开始分裂
- **一句话概念**：即使每个人只有温和偏好，整个城市也可能出现明显分区吗？
- **知识素材**：谢林隔离模型、局部偏好、集体涌现、空间分布。
- **视觉主线**：棋盘上随机混合的不同色点 → 根据邻居组成决定是否移动 → 数百次迭代后形成清晰群落。
- **高潮镜头**：原本杂乱的粒子棋盘，在连续移动中逐步出现宏观分区。
- **科学边界**：这是对某种局部偏好机制的模型展示，不能作为现实隔离现象的唯一解释。
- **状态**：待讨论。

### T16｜宇宙为何无法倒带
- **一句话概念**：物理方程有时容许时间反演，日常世界为什么明显分得出过去和未来？
- **知识素材**：热力学第二定律、熵、统计物理、时间之箭、低熵初始条件。
- **视觉主线**：玻璃落地破碎 → 倒放 → 分子/状态空间可视化 → 低熵与高熵宏观状态对比。
- **高潮镜头**：无数碎片仿佛将要重新合拢，却被越来越庞大的微观可能状态可视化所吞没。
- **科学边界**：不能说玻璃重组被基本物理定律绝对禁止；应解释其宏观概率极低。
- **状态**：待讨论。

### T17｜一场看不见的传播
- **一句话概念**：一个微小的信号，怎样穿过整个复杂网络？
- **知识素材**：SIR 模型、网络传播、阈值扩散、接触结构。
- **视觉主线**：单个节点点亮 → 邻居连锁传播 → 分群与关键节点显现 → 改变传播条件后比较。
- **高潮镜头**：整张暗色城市地图被一条条细金色脉冲逐步点亮。
- **科学边界**：病毒传播、谣言传播与信息扩散规则不同；正式剧本需要明确模型对象。
- **状态**：待讨论。

### T18｜平均人的幻觉
- **一句话概念**：如果平均数完全相同，数据也可能讲述截然不同的故事。
- **知识素材**：均值、中位数、方差、分布、安斯库姆四重奏。
- **视觉主线**：四份统计表看上去相似 → 坐标轴从纸面浮起 → 四幅不同的散点图出现。
- **高潮镜头**：相似的几行数字漂浮空中，突然排列成四幅差异显著的数据图像。
- **科学边界**：展示的数据应可验证且真实对应统计量，不虚构不自洽图形。
- **状态**：待讨论。

### T19｜信号与噪声
- **一句话概念**：世界充满干扰，我们如何从不确定的信息中找出真正的信号？
- **知识素材**：贝叶斯推断、信号检测理论、信息熵、噪声中的模式识别。
- **视觉主线**：杂乱星点 → 微弱信号出现 → 根据证据更新概率 → 有意义的图形逐渐清晰。
- **高潮镜头**：黑金粒子海中，模糊信号在连续证据作用下逐渐显露，但仍保留不确定范围。
- **科学边界**：不要把贝叶斯概率更新误当成“算法必定找到真相”；合理标出先验与证据。
- **状态**：待讨论。

### T20｜消失的确定性
- **一句话概念**：为什么测量越来越精密，我们仍然无法无限准确地预测未来？

## 04｜统一制作约束（讨论每条时默认生效）

1. **独立账号系列**：理论视觉纪录片，不并入「如果放映局」的生活脑洞动画。
2. **美术基线**：深黑、暗金、羊皮纸色，历史科学纪录片；与《运气的形状》保持相近的设计气质，但所有镜头和图形重新创作。
3. **横屏**：默认 1920 × 1080，30fps；构图针对 16:9 原生设计。
4. **无旁白**：知识通过真实演化的动态图形、关键年份、人物/文献、简短注释传递，不靠大段字幕。
5. **科学准确**：演示应来自明确模型或历史研究；避免把不同学科中的同名术语混为一谈；正式 PRD 需有资料来源。
6. **声音**：Remotion 提供音效与音效轨，最终 BGM 用户后期制作；不得自动抓取参考视频配乐。
7. **制作质量**：优先连续空间运动与有因果的形态变化，避免 PPT 过场、仅数字跳动、素材幻灯片及无意义粒子爆炸。
8. **智能体交付**：每条正式项目应提供 `prd.md`、逐秒时间线、场景组件、动态数据来源、素材清单、音效清单、运行脚本、验证截图与可播放成片。
9. **风格验收**：完整项目开工前，建议先做 10～15 秒高完成度的风格样片，确认美术和运动语言后继续。
