# 《运气的形状》深度视听与 Remotion 制作语言拆解

> **用途：** 供 Codex、Claude Code、GPT 系列模型及其他编程/设计智能体阅读。与原片 `运气的形状.mp4` 同时提供，作为制作原创「历史科学视觉纪录片」的**风格、叙事、工程与验收参考**。  
> **文档性质：** 实际视频观察 + 制作方法反推 + 可实施的工程规范。**不是**原作者源码、项目工程或官方幕后制作说明。  
> **分析基准：** 用户提供的本地视频，非网上同名视频的推测。  
> **核心要求：** 学其视觉语法、信息密度、实验表达和完成度；**不要照搬**它的台词、镜头、数学实验排列、品牌标记、配乐或具体画面。

## 00｜给执行智能体的 90 秒摘要（请优先阅读）

这部参考片的高级感，不是「金色字体 + 黑背景 + 粒子」三个简单元素的总和，而是以下**八套系统一起工作**：

1. **抽象标题具象化。** 《运气的形状》是贯穿全片的隐喻，起始是一枚无法预知结果的骰子，最终通过大量概率实验让“随机的整体形状”出现，结尾回到骰子。
2. **一根历史时间轴带动全部内容。** 画面左上角的大号金色年份与人物姓名是持续存在的导航系统；右上角的小号外文文献、书名、注释构成第二层可信度。
3. **每段不是讲术语，而是在做实验。** 先亮出一个难题/物件，再让真实规则在画面里运行，最后出现可理解的结果；用少量屏幕文字完成点题。
4. **单镜头一个主视觉命题。** 骰子、赌局分配、骰子组合、分支概率树、豆子抽样、柱状分布、投针、滚珠板，各幕有唯一视觉核心，不堆叠无关元素。
5. **黑色为绝对主色，金色只用来照亮重要结论。** 多数画面极暗，发光面积很小，重要数字或概念才被明显点亮；背景有低强度暖棕/深蓝环境变化。
6. **排版接近古典文献和博物馆展陈。** 衬线大年份、细小人物标签、古籍引文、数学符号、细描边图形、低饱和纸张纹理构成一整套一致的语言。
7. **动画是渐进变化，不是花哨切镜。** 数字计数、点列增长、路径分叉、统计曲线逼近、硬币/骰子旋转、落球堆积等过程让观众“看着结论产生”。
8. **节奏像有音乐的默片。** 无可辨识的讲解旁白，以简短底部文字、场景中的动作、音效和音乐推进；视觉峰值往往与概念被证明的瞬间重合。

**执行准则：请先制作一组 12–18 秒可验证的原创样片：古典年份入场 → 单个实体出现 → 规则演化 → 结果高亮 → 字幕点题。如果这段还像网页、PPT、科普信息卡片，就不要继续量产整片。**

## 02｜这部片到底属于什么风格？

建议准确命名为：

**黑金古典科学视觉纪录片（Dark-Gold Historical Scientific Motion Documentary）**

这是一个**跨媒介设计风格定义**，并不是某个现成 Remotion 模板或行业唯一正式流派。它由以下元素合成：

| 维度 | 参考片具体表现 | 缺失后会变成什么 |
|---|---|---|
| 叙事 | 从掷骰子的命运观 → 概率数学化 → 当代总结 | 堆知识点、百科卡片 |
| 美术 | 近黑底、暖金/骨白信息、极少的红色强调 | 普通暗色仪表盘 |
| 时代感 | 年份、历史学者、拉丁文/法文/英文文献、古籍标题 | 现代营销宣传片 |
| 科学感 | 概率树、统计曲线、几何投针、正态分布 | 纯抒情艺术动画 |
| 物质感 | 骰子、指骨、纸页、硬币、圆盘、金属装置 | 没有具体锚点的抽象粒子海 |
| 运动 | 慢入场、精密运行、逐步揭示、高潮再收敛 | 大量粗暴缩放和炫光 |
| 文字 | 少量短句，层级极清楚 | 重度字幕/大字报 |
| 声音 | 音乐作为整体推动，关键动作适合稀疏 SFX | 无动态张力的静态图表 |

最重要的判断：**它像一篇被拍成电影的科学论文，而不是给论文加动效的 PPT。**

## 03｜整体叙事：为什么“没有旁白”仍然看得懂？

### 3.1 宏观四幕式结构 [O/I]

**第一幕｜设问与隐喻（约 0–16 s）**  
从具体的投掷物开始，提出“运气能否被计算”的问题，揭示题目，随后借古代游戏进入历史。

**第二幕｜一个问题引出另一个问题（约 16–67 s）**  
赌局分配 → 骰子组合 → 计算公平性的分歧 → 概率树。不是数学家名单，而是问题不断被修正、被继续研究。

**第三幕｜个体不可预测，整体出现形状（约 67–114 s）**  
死亡统计、抽样比例、正态曲线、投针求 π、高尔顿板：镜头从一次事件逐渐扩大到大量重复事件。**这是标题真正兑现的部分。**

**第四幕｜理论收束与环形结尾（约 114–128 s）**  
公理化形式 → 回到现代骰子 → 再次出现片名。观众重新看同一个骰子，意义已变。

**约 128–133 s** 是平台传播附加画面，与正片在视觉和叙事上分离。

### 3.2 它不是把 11 个“定理”挤在一起

片中出现**数学问题、历史人物、概率定律、统计应用、几何实验、实物装置、数学公理化**等不同层级内容。建议把它们称作“历史/知识节点”，不能把每个名字都包装成独立定理。视频的重点不是数量，而是**每个节点推动下一步认知**。

### 3.3 贯穿全片的五条视觉线索

1. **命运的实物：** 骰子／指骨／硬币不断换形态，始终提醒观众“随机性来自一次不可预知的结果”。
2. **年份的锚点：** 画面顶部持续提示时间在向后推进；观众即使没有旁白也知道正在跨越几个世纪。
3. **数值的积累：** 50:20、9 点 vs 10 点、25 vs 27、51.8% vs 49.1%、3/5、π≈3.14、分布曲线等承担知识表达。
4. **从离散到连续：** 骰面点数、分支树、抽样小点、柱状图，最后成为平滑分布曲线。
5. **一句话点题：** 每个段落底部短句承担叙事，而不是解释全部学术推导。

### 3.4 没旁白时，理解链条必须完整

每个核心知识点至少完成三个可见步骤：

`提出问题或设置 → 画面中运行规则 → 数值/形状出现结果`

可选第四步：`一句话解释结果意味着什么`。

如果新作品出现“姓名和理论标题上屏 → 过场 → 下一个理论”，即使颜色与本片一致，也**没有学到它的核心方法**。

## 04｜逐场景时间轴：参考片的真实视觉结构

> 本节是给模型最重要的导航资料之一。时间码近似；每条均可对照原片。**不要把以下具体实验按原顺序复制到新项目**。新项目要保留的是每一幕的功能与技术动作类别。

### 04-01｜00:00–00:06：骰子出现，建立问题

- **[O] 主体：** 一枚奶油白/骨白立方骰子，圆角边缘，黑色点数和少量红点标识；位于暗色背景中央偏上，缓慢转动/空间翻滚。
- **[O] 环境：** 深黑偏棕背景、极弱的圆形辉光、零星漂浮小点；没有铺满的星空。
- **[O] 文本：** 底部先出现“骰子落下之前，谁也不知道答案”一类设问，紧接“运气，能被计算吗？”（参考原片时间附近的文字，以原视频为准）。
- **[I] 运动：** 骰子的姿态变化有明确三维体积，不是纯 2D 图片水平旋转；阴影和明暗随角度变化。
- **作用：** 以**一个可识别的实物**让抽象“概率”可以被看见。
- **可迁移规则：** 抽象片名先找一个视觉代言物，如“时间→时钟”“代价→金币”“信任→两枚可交换筹码”。

### 04-02｜00:06–00:11：黄金片名，第一视觉峰值

- **[O] 中文大标题：** `运气的形状`，中央黄金色大字，明显的亮部、暗边与辉光。
- **[O] 顶部小字：** `DE FORMA FORTUNAE`，字母间距宽，像古典外文副标题。
- **[O] 装饰：** 中心向外细光线/放射纹与下方浅金细线，不是粗壮特效。
- **[I] 镜头节奏：** 由骰子的慢速运动切换到稳重的标题定格，形成第一次呼吸。
- **作用：** 题目在片头先给一个“形而上”答案，后文科学实验负责解释。
- **可迁移规则：** 主标题只出现必要次数；不要每个知识点都用同等级的大字爆炸。

### 04-03｜00:11–00:17：古代投掷物与命运之轮

- **[O] 画面：** 骨质/指骨状投掷物在低处平行排列，上方可见`ALEA IACTA EST`大字以及圆形命运轮/古典图表符号。
- **[O] 字幕：** 命运、胜败与投掷游戏联系在一起。
- **[I] 结构：** 从现代骰子退回历史源头，形成“倒回历史再向前走”的装置。
- **可迁移规则：** 用古老器物/历史文献为科学问题建立时间厚度；别用与本论点无关的“复古装饰”。

### 04-04｜约 00:17–00:27：帕乔利赌局中断问题

- **[O] 上方：** 金色年份从过渡状态进入 `1494`，配学者姓名；右上角有书籍/文献提示。
- **[O] 主画面：** 两方博弈数字 `甲 50` 与 `乙 20`，金币、下注/结果标记、`中断`字样、比例与分割图形。
- **[O] 动画方法：** 数字、刻度、金币/分区随段落推进不断变换，最终把公平分配问题具体化。
- **[O] 对比色：** 黄色/金色代表一方，赤红代表另一方或警示/错判；红色用量极少。
- **作用：** 故意先呈现一种看似合理的分法，再通过后续历史认识指出问题复杂得多。
- **可迁移规则：** 同一幕使用**可比较的量**，而不是只给结论数值。

### 04-05｜约 00:27–00:34：卡尔达诺与骰子组合

- **[O] 元素：** 单枚骰子、写着 `1/6` 的小方块、十字形或展开式组合、多个骰子。
- **[O] 版式：** 依旧左上年份/姓名、右上书名、中央极简演示；很多区域保持近黑。
- **作用：** 把“每面等可能”变成一眼能懂的图形结构。
- **可迁移规则：** 一条原理只给一种图解方法，不用同时上三套图表。

### 04-06｜约 00:34–00:42：伽利略，9 点与 10 点哪个更常见

- **[O] 主画面：** 左右两列骰子组合，左 `9点`，右 `10点`；各行骰子组合配倍数，最后显示 `25 种可能` / `27 种可能`。
- **[O] 文字：** 底部提醒“骰子各种组合，顺序也要算”一类区别。
- **[O] 构图：** 对称比较，中央一条弱化的 `VS`；左右均衡，注释收于局部。
- **[I] 动效：** 组合逐项出现，数字渐进统计；不是一次性把整张大表闪上屏。
- **作用：** 观众看到“看上去类似”的两组数字其实不等价。
- **可迁移规则：** 当科学问题是比较时，采用严格对称的视觉结构和同步动画。

### 04-07｜约 00:42–00:50：帕斯卡、费马与正确概率

- **[O] 主画面：** 两个深色描边实验框，`赌局 A` 与 `赌局 B`，骰子与结果序列、进度条、金色及红色数值。
- **[O] 关键数：** 大约 `51.8%` 对 `49.1%`（对应画面示例中的不同规则；需以实际配置核算、原片数值只作视觉观察）。
- **[O] 细节：** 框角微亮，标签小而精密；有印章感的红色小符号。
- **作用：** 把古人的直觉之争变成可以计算的概率差。
- **可迁移规则：** 同屏多数据时，先统一单位、尺度和视觉权重，再突出差异。

### 04-08｜约 00:50–00:57：地图、书信和思想传播

- **[O] 画面：** 法国轮廓地图、两个城市位置、引用式文本与手稿排版。
- **[O] 色彩：** 地图边线暗金，地形内部几乎黑色；文字更接近暖灰白。
- **[I] 叙事动作：** 从纯数学图解暂时切到真实历史通信，避免连续看数据产生疲劳。
- **可迁移规则：** 一段纯数据动画之后，用地图/器物/原始文献作“视觉换气”，但主题不能中断。

### 04-09｜约 00:57–01:06：分支树，未来可能性逐层展开

- **[O] 画面：** 金币/初始赌局置于画面左侧；概率树沿水平方向连续分叉，金色与赤红的路径交织；右端有结果列，显示约 `15:1` 等比例信息。
- **[O] 运动：** 线条从一个节点生长为多个节点；节点与路径的出现顺序本身就是推导过程。
- **作用：** 从“已经发生的比分”转向“尚未发生的所有未来路径”。这是整片叙事上很有力量的抽象升级。
- **可迁移规则：** 一棵真实逻辑树比任意漫天粒子更高级。每条分支对应清晰的数据含义。

### 04-10｜约 01:06–01:74（即 01:06–01:14）：格朗特与人口统计

- **[O] 画面：** 伦敦历史死亡记录样式的纸页/表格，随后变成大量密集的小点，形成对死亡数据/人口的群体表现。
- **[O] 历史年份：** `1662` 左上，右上文献引用。
- **[O] 字幕方向：** 单个人的生死无法预知，整座城市的统计却可能呈现规律。
- **作用：** 概率从赌桌转向真实世界中的群体数据。
- **可迁移规则：** 用**尺度切换**制造叙事进步：从一个人、一颗骰子扩到几千个样本。

### 04-11｜约 01:14–01:24：伯努利抽样，大数定律可视化

- **[O] 画面：** 左侧装有白球/黑球的透明坛罐；右侧是随抽取次数增长的比例曲线。
- **[O] 图表：** 横轴样本数逐渐扩大，黄色折线从猛烈波动到靠近 `3/5` 的参考水平线。画面中出现 `第 83 次`、`第 1,893 次`、`第 25,550 次`等逐步增长的样本数。
- **[O] 色彩：** 线条温暖浅金，参考虚线克制，实验容器细金边，背景黑。
- **作用：** 这段不是“展示一条统计曲线”，而是**让观众亲眼看见偶然逐渐被重复试验平均掉**。
- **可迁移规则：** **过程决定可信度。** 若用预计算轨迹，仍要保证它源自实际随机抽样而不是用随意的手绘噪声曲线冒充科学结果。

### 04-12｜约 01:24–01:29：棣莫弗，柱状图向钟形曲线变化

- **[O] 画面：** 不同数量抛硬币实验所对应的直方柱，变化到密集柱条构成的对称钟形分布，右侧出现精细的曲线标识。
- **[O] 文案：** 抛的硬币越多，柱子越细，曲线逐渐出现。
- **作用：** 把离散分布与连续近似之间的联系变成“形态学转场”。
- **可迁移规则：** 从上段“曲线趋稳”平滑升级到本段“分布成形”，画面不是平铺并列，而有递进。

### 04-13｜约 01:29–01:37：布丰投针，随机几何计算 π

- **[O] 主画面：** 木质/深棕台面或标尺状平面，上面大量细线段/针随机落下；右下方的计算板持续记录`投针`/`压线`/`π≈2N÷K`一类数量与结果。
- **[O] 关键阶段：** 约 95 秒时画面出现巨大的发光 `π≈3.14`。
- **[O] 运动：** 针以不同角度、位置不断叠加，累计数量越来越大；结果数值随之收敛。
- **作用：** 极强的“低级操作产生高级常数”的反差。是本片的第二大认知高潮。
- **可迁移规则：** 必须采用正确模拟几何条件。不要用硬编码常数去冒充物理过程。

### 04-14｜约 01:37–01:42：拉普拉斯，概率观念被提升

- **[O] 画面：** 深蓝黑背景中极淡的天体轨道/椭圆与散点，中央以宽松排版出现一段较完整的中文结论，上方有法文式引文。
- **[O] 字体：** 中央长句比通常字幕更庄重，部分词语加金色强调。
- **作用：** 给观众短暂的哲学性停顿，避免一直处于计算冲刺。
- **可迁移规则：** 长句只能放在**没有复杂主动画**的镜头，并给充分阅读时间。

### 04-15｜约 01:42–01:54：高尔顿板，小球落下形成分布

- **[O] 主画面：** 精密边框包裹的高尔顿板。大量发光小球经过三角排列的钉子，最终落入下方多个窄槽。
- **[O] 时间演化：** 前期球很稀疏，约 108–112 秒逐渐出现小山般的分布轮廓，随后叠加平滑钟形线。
- **[O] 布局转移：** 前期装置居中，收束时右侧出现解释文字和引文，左侧保留已经形成的分布图，构成“实验结果 + 解释”的二分布局。
- **作用：** **标题《运气的形状》的最具象兑现。** 单球无法预测从哪边落，但大量球有统计形态。
- **可迁移规则：** 把最有动感、最让人舒适的过程动画放在后段，让全片结构真正抵达一个视觉目的地。

### 04-16｜约 01:54–02:00：柯尔莫哥洛夫，概率公理化

- **[O] 主画面：** 暗背景中出现 `P(A) ≥ 0`、`P(Ω)=1`、集合相加等数学符号，左侧有 I/II/III 的层级，右侧是简短解释。
- **[O] 版式：** 有真实数学论文页面的节制感，但仍留足空白。
- **作用：** 历史故事从经验问题和实验归纳抵达严谨的数学语言。
- **可迁移规则：** 使用公式应该是为了**收束前文意义**，而不是炫耀难度。

### 04-17｜约 02:00–02:08：回到骰子，首尾闭环

- **[O] 左上年份：** `2026`（出现在正片当下位置）。
- **[O] 主体：** 最初的白色骰子再次转动，周围浮现很淡的钟形分布线和数值/概率痕迹。
- **[O] 底部文字：** 提示“下一次会掷出几点？依然没有人知道”，再引导“但运气，从此有了……”的结尾意思。
- **作用：** 保留科学准确性：概率研究不等于能预测下一次具体骰面；数学揭示的是群体规律。
- **可迁移规则：** 最后回到片头实物，但背景含义已经被中段重新定义。**首尾同形、认知不同**。

### 04-18｜约 02:05–02:08：片名回归和出品信息

- **[O] 屏幕中央再次出现大金色片名、下方横线与细小署名/说明，整体像一张精装书的扉页。**
- **作用：** 情绪与节奏上落地，不要用“关注点赞”破坏故事完成度。

### 04-19｜约 02:08–02:13：平台结束页

## 05｜色彩：为何黑金没有变成“土豪金”？

### 5.1 色彩分工，而非统一贴滤镜 [O]

| 色彩角色 | 建议可执行色值（重新设计，不声称为原片像素值） | 用途与约束 |
|---|---|---|
| 主背景黑 | `#08090C` / `#0D0B0A` | 80% 以上视觉面积的基础色；依据场景可略偏深蓝或暖棕 |
| 低频暖背景 | `#21180F` / `#2B2016` | 极淡中央光晕、古代器物场景的纸褐环境 |
| 历史暗金 | `#B5965A` | 年份、边线、装置结构、次级重点 |
| 主强调金 | `#D4B476` / `#E7C98F` | 实验最终结果、标题、重要结论 |
| 骨白/纸白 | `#E8DCC5` / `#EFE6D7` | 骰子、卡片、主要短句、数学白字 |
| 弱注释灰 | `#8B8272` / `#B0A58F` | 人物副注、书籍信息、次级单位 |
| 暗赤红 | `#A54E42` / `#BA594A` | 赌局另一方、错误/对照、印章；全片占比低 |
| 装置暗线 | `#4F432F` | 边框、刻度、坐标、纸张暗纹 |

**禁止把以上色值理解成“每个像素必须相同”。** 同一材料的金属高光有自然的明暗变化，整段画面还会受到纹理、伽马、压缩影响。色板只作为原创工程中的设计 token。

### 5.2 实际亮度测量 [M]

抽取原片多个代表性帧做灰度直方图检查，发现：

- 正片中多数所选帧的**亮度中位数约 9–17 / 255**；
- 90% 分位的亮度多落在 **约 18–43 / 255**；
- 所选帧中亮度 `>128` 的面积一般仅约 **1.3%–5.8%**（含水印和部分高对比元素）。

这说明：**暗部不仅是“黑色背景”，而是整体亮度分布被强烈压低，亮点极为稀疏。**

### 5.3 应该怎么用 [R]

- 在主实验镜头里，先把背景与装置的整体曝光拉低，再决定哪一个结果值得更亮。
- 避免所有数字都发光；只有“观众需要此刻看见”的数字才亮。
- 用两级 glow：轻微的局部实物边缘辉光 + 偶尔的结论性 bloom；多数时间不要泛白。
- 金色应至少有**暗金结构线 / 中金文字 / 骨白强高光**三档，而不是一种通用纯黄。
- 冷暖切换要有叙事依据：如古代棋局偏暖棕，统计与公理化偏深蓝黑。
- 远处尘粒不要像屏保：粒径、速度、密度均极低；只在明暗过渡时稍能察觉。

### 5.4 一个可复用的视觉优先级

`运动中的关键物体 > 关键数值/结论 > 年份/姓名 > 背景书名与学术注释 > 装饰粒子`

任何背景装饰如果抢到高于主体的视觉对比度，就应该削弱。

## 06｜版式系统：屏幕四角有稳定功能

以原片 `1280 × 720` 观测，给 1920×1080 原创工程提供如下**比例化参考网格**。这是统计多个画面后的排版建议，不是逐帧自动追踪出的严格边界：

```
┌────────────────────────── 16 : 9 ──────────────────────────┐
│  左上：年份/人物                    右上：书名/文献/注释    │
│  x≈5–22% y≈5–18%                  x≈72–96% y≈5–18%       │
│                                                             │
│               主实验视觉区域 / 运动发生区                   │
│               x≈12–89%  y≈21–78%                           │
│                                                             │
│              少量底部说明文字 / 结果短句                    │
│              x≈15–85%  y≈82–92%                            │
└─────────────────────────────────────────────────────────────┘
```

### 6.1 左上：时间轴是导航，不是装饰 [O]

- 年份通常很大、金色、衬线风格，右侧或上方可能有“约”或纪元标记。
- 年份下方通常带人物与地点，如“佛罗伦萨·伽利略”或“巴黎·帕斯卡·费马”。
- 年份变化本身构成跨场景转场。它**不一定每秒都运动**，静止阶段也很重要。
- 新作品建议把年份做成一个共享 `HistoryHeader` 组件，场景只提供 `{year, name, place}`，避免每个镜头重造字间距与位置。

### 6.2 右上：文献锚点提供“学术可信感” [O]

- 外文书名或拉丁文、中文译名、副注、时间、方形红印等形成“小型文献目录卡片”。
- 它们的可读性低于主标题，但需要风格统一。
- **不能为了装高级编造论文名、拉丁语、年份和引用出处。** 可核查的真实文献才上屏；否则用“实验编号、章节名称”等原创说明替代。

### 6.3 中央：每一镜通常只干一件事 [O]

- 主体可以横跨中央（骰子、圆盘、树枝），也可以左右双区（9/10 点、坛罐+曲线）。
- 核心信息在屏幕中部有连续动作，边角资料是“观看辅助”，不应反过来占满中心。
- 原片多个章节大量使用**三分法 / 中心轴 / 左右等宽**构图；不用现代 dashboard 卡片的全屏栅格密铺。

### 6.4 底部：一句话结论是“无声旁白” [O]

- 尽量一行，个别镜头允许二行。
- 多数时候在靠下中轴附近出现，暖白/骨白字色。
- 文字短、留白大、不闪烁，读完时动画也应接近一个小的完成状态。
- 原片平台水印在右下角，这不是风格设计内容；新作品不应仿制平台水印。

### 6.5 从 1280×720 到 1920×1080 [R]

不要照抄像素坐标。推荐采用**设计基准 1920×1080、逻辑上按百分比布局**。示意：

| 元素 | 1920×1080 设计起点 | 备注 |
|---|---:|---|
| 左上年份左边距 | 约 96 px | 接近 5% 宽度 |
| 左上年份顶边距 | 约 54 px | 接近 5% 高度 |
| 右上文献右边距 | 约 96 px | 统一外边距 |
| 中央动态主区 | x≈220–1710, y≈200–860 | 必须按单幕重设比例 |
| 底部说明中心线 | y≈950–995 | 根据平台安全区调整 |
| 标题最大字块宽度 | 画宽 55%–75% | 不靠放大到触边获得震撼 |

注意：抖音等平台横屏的 UI 遮挡随播放器环境变化，应额外检查实际发布安全区。

## 07｜字体：要像“论文、史书、博物馆展签”

### 7.1 原片可观察的层级 [O]

1. **H0 片名：** 厚重、高对比的中文标题字形，有金属光泽、暖亮边沿和显著层次。
2. **H1 年份：** 大号古典衬线阿拉伯数字，像书籍扉页或科学史年表。
3. **H2 理论/数据：** 精细 serif 数字，如 `9`、`10`、`π≈3.14`，尺寸大但不过分张扬。
4. **H3 底部短句：** 读得清的中文正文，常呈近白色或羊皮纸色。
5. **H4 文献题注：** 极细小外文斜体/serif 与中文辅助字。

### 7.2 新项目的字体组合 [R]

- 标题：选择合法可用的高品质中文宋/明体或专用古典衬线标题字体。
- 年份、外文与数学数字：选择具有旧式书籍气质的 serif（如合法安装的 Cormorant Garamond、EB Garamond、Libre Baskerville 等，具体是否适合汉字需另配中文字体）。
- 辅助中文：思源宋体或思源黑体的适当字重，避免低清晰度。
- **优先保证跨平台渲染一致：** 字体文件本地合法存放、Remotion 预加载、验证中文字符覆盖、不要运行时依赖远程字库。

### 7.3 字体应该有“少而分明”的层次 [R]

- 一个镜头中文字权重最多三级：年份、中心内容、注释。
- 尽量不使用胶囊标签、按钮造型、现代弹窗边框。
- 年份可采用轻微字距、横线和低透明度副标题。
- 文献小字“能让观众识别其存在”不等于“必须逐字可读”。但决定科学结论的文字必须清晰。
- 数字对齐用 tabular lining numerals 或等宽数字特性，尤其倒计时和统计数值。

## 08｜材质与纹理：为什么背景不是一整块死黑？

### 8.1 画面层可观察到的质感 [O/I]

- **暗角与弱中心光：** 特定场景中央有极弱的褐金漫反射，边缘仍向黑靠拢。
- **低频纹理：** 暗部有细小不规则颗粒，看上去更接近胶片颗粒/旧纸肌理，而不是规则渐变。
- **悬浮灰尘：** 少量亮粒子缓慢移动，赋予“展柜内尘埃”感。
- **描边纹理：** 金色线条并非都像完美霓虹；部分具有微弱强弱与边缘扩散。
- **局部纸张：** 死亡统计记录和文献段落，才让羊皮纸成为可见实物；**不是每一幕都铺满黄色纸背景**。
- **红色印章：** 若出现，尺寸小、功能明确，扮演“文献索引/对照阵营”的角色。

### 8.2 推荐背景分层 [R]

一个高质量背景至少由下面 4–6 层组成，且每层非常轻：

```text
L0: 不透明近黑底色
L1: 根据章节变化的深蓝/暖棕大尺度径向光
L2: 极细的静态颗粒或缓动胶片噪声
L3: 稀疏的远景尘粒（低 alpha、不同深度）
L4: 按需出现的科学结构底纹（放射线、经纬线、轨道、刻度）
L5: 主体下方的接触阴影/非常低强度环境反光
```

**禁止：** 背景满屏跑动星星、明显平铺纹理、噪声点闪得刺眼、强烈 RGB 故障风、过度 Bloom、所有场景用同一个渐变贴图。

### 8.3 材料库建议 [R]

- `parchment_subtle.png`：淡旧纸，仅文献/器物使用；不做重度脏污。
- `fine_grain.png`：可无缝循环的微粒纹理。
- `warm_dust.svg` / deterministic point cloud：固定种子分布尘点。
- `gold_line_gradient`：暗金→亮金→暗金的小幅线条光泽。
- `edge_vignette`：极弱外围压暗。
- `historical_hairline.svg`：细线、刻度、章纹等几何装饰。

> 材质的优先级低于实验可信度；如果用错算法，即使纹理很漂亮也不合格。

## 09｜动画的语言：看似克制，实际上一直有事发生

### 9.1 片中主要运动类型 [O/I]

| 动作类型 | 参考片例子 | 观看意义 | 可实施方式（不是作者源码） |
|---|---|---|---|
| 物体三维旋转 | 骰子缓慢翻转 | 建立实物与不确定性 | Three.js mesh / 预制序列帧 |
| 渐进绘制 | 分支树逐层分叉 | 让过程可追踪 | SVG strokeDashoffset / path reveal |
| 离散计数 | 组合种数、重复试验 | 强化实验真实推进 | 数据驱动文本、累积数组 |
| 粒子群演化 | 人口点、滚珠 | 个人随机与群体规律反差 | 预计算粒子状态 / Canvas/WebGL |
| 分布形变 | 直方图→钟形曲线 | 离散到连续的概念过渡 | 同一数据模型双表示插值 |
| 路径追踪 | 论文、书信、地图、概率路径 | 让历史与逻辑发生关联 | SVG 路径、mask、stroke reveal |
| 高亮聚焦 | 数据或公式结论放亮 | 让观众知道看哪里 | 局部 glow、opacity、scale 微动 |
| 空间微推 | 器物/文字镜头慢推近 | 增加电影感 | 2.5D camera / translate+scale |
| 光线/尘埃 | 片名与暗背景 | 增加仪式感 | deterministic noise + sparse particles |
| 稳定定格 | 结论出现后暂停 | 留给观众认知时间 | Hold frames，不强迫持续移动 |

### 9.2 一个典型知识段的五拍节奏 [R]

`A 物体入场（0.8–1.5s） → B 规则呈现（1–2s） → C 连续演算（3–7s） → D 结果揭示（0.8–1.5s） → E 阅读停留（1–2s）`

具体时间依据内容复杂度变；不能所有章节固定同一时长，否则会机械化。

### 9.3 微动效参数建议 [R]

这些是**新工程的起始建议**，不是对原片逐帧测出的参数：

- 普通信息出现：约 8–18 帧的 opacity/translate 缓入。
- 数字从 0 增长：以真实样本进度绑定帧，结束时停留 15–45 帧。
- 物体镜头推近：10 秒内的整体 scale 增量常控制在约 2%–7%，优先平稳。
- 发光结果强调：可用不超过 1.03–1.06 的轻脉冲 scale 或 0.2–0.5 秒的辉光提升；不要大跳动。
- 分支/线条绘制：沿真实路径方向发生，节点先有父后有子。
- 小球碰撞：由预计算轨迹决定，视觉弹性可以是少量次要装饰，不应违反几何约束。

### 9.4 “不持续动”也是高级感

没有旁白的画面尤其需要留够看字时间。参考片的高能过程与安静文字页交替出现。**如果每 0.5 秒都要打一个重音、不断快切，就会失去科学纪录片的克制气质。**

## 10｜实验可视化设计法：关键不是“做动图”，是“展示证据”

### 10.1 六层模型 [R]

对每个理论先完成以下定义，再写代码：

1. **问题：** 普通人会问什么？
2. **可观察量：** 什么会在画面中变化（次数、位置、频率、比例、时间）？
3. **可操作规则：** 真实数学关系或实验程序是什么？
4. **初始条件：** 一开始观众看到哪些变量？
5. **演化过程：** 数据怎样逐帧变化？
6. **可视化结论：** 最后呈现的形状/数字为什么能支撑结论？

### 10.2 参考片里的三个典范

**典范 A｜骰子 9 点 vs 10 点**

- 问题：哪个点数和更常见？
- 规则：枚举所有合法的三个骰子结果，对排列进行计数。
- 画面：左右并排、组合逐行出现、每行乘数/总数累积。
- 结论：不同点数和对应的总组合数量不同。
- 技术要义：**数据驱动排列**，不是用几张骰子照片来回轮播。

**典范 B｜伯努利抽样**

- 问题：随机抽取怎么会越来越接近一个比例？
- 规则：模拟按已设定概率抽取，记录累计平均。
- 画面：左边容器，右边对数尺度或递增采样的折线，真实比例作为参考虚线。
- 结论：一次试验可能很偏，重复足够多后常会逐步靠近整体概率。
- 技术要义：**曲线数据必须由真实采样得到**，还需保证图表横轴表达正确。

**典范 C｜高尔顿板**

- 问题：每颗球随机偏左偏右，为何整体堆成山形？
- 规则：独立对称随机左右决策（或物理参数模型），根据终点分槽计数。
- 画面：稀疏落球→密集落球→柱状堆积→平滑参考线。
- 结论：无序的个体行为，在重复样本中形成规律性的总体分布。
- 技术要义：让“逐颗落球”的路径与“底部分布”的数据相互一致。

### 10.3 绝不能发生的科学视觉错误

- 线条和数字明明不相关，却被蒙太奇放在一起假装推导。
- 曲线先画成最终结果，再假装是随机试验的实时输出。
- 统计图横轴、纵轴暗含不同尺度，未经说明就拿高度比较。
- 反复抽样没有说明是否放回，和模型假设矛盾。
- 通过极端审美变形，使观众误判真实比例或结果差距。
- 不区分“概率值”“模拟频率”“单次结果”“模型假设”。
- 用真实科学家姓名包装没有来源的杜撰引语。

## 11｜历史纪录片“知识厚度”从哪里来？

### 11.1 一个章节的可视化信息分层

**第一层（必须看懂）：** 时间、核心实体、实验过程、结果。

**第二层（增加真实感）：** 人名、城市、文献标题、年份、精炼引文。

**第三层（展陈细节）：** 拉丁文小字、纸页纹理、索引编号、薄线刻度、旧式章纹。

这三层不能互相替代。只有第三层没有第一层，成片就会华丽而空洞。

### 11.2 文献和历史人物的功能

- 历史信息不是用来让人背诵，是让观众感到**“这套规律经历了人类数百年的探索”**。
- 学者/文献出现时，最好伴随**其贡献所解决的问题的可视化**。
- 地图书信段是视觉换气，不是知识堆砌；它让数学发生在人类世界。
- 可使用真实可核验的公版文献、地图与图表，自制现代化描摹；注意来源、版权与译法准确性。

### 11.3 对新作品的推荐表格 [R]

| 内容类型 | 应有的历史锚 | 适合的中央可视化 | 结果形式 |
|---|---|---|---|
| 数学定理 | 研究者、年份、原始问题 | 数据结构实际演化 | 公式/曲线/几何图 |
| 物理实验 | 实验年份、装置、条件 | 仪器运动与实测量 | 数据差异/轨迹 |
| 心理实验 | 研究问题、设计、参与者 | 条件 A/B 的对照行为 | 分布、偏差、解释 |
| 社会模型 | 模型作者、假设、边界 | 大量主体按规则互动 | 群体形态/对照结果 |
| 经济学概念 | 历史案例、选择约束 | 资源流动、决策分叉 | 机会成本/权衡 |

## 12｜片名与文案：让一个抽象词成为视觉结果

### 12.1 好标题的三个条件 [I/R]

- 一个富于想象的**抽象对象**：运气、时间、秩序、记忆、代价、信任、无限。
- 一个不寻常的**物理属性/动作**：形状、重量、速度、裂缝、回声、边界、引力、房间。
- 全片能拍出这一属性，而不是只写在封面。

可参考这种结构（只作为命名法）：

- 《时间并不均匀》：不同物理时钟/主观判断的差异逐渐显现。
- 《看不见的代价》：选中一条路线时，未被选择的路线逐渐暗去。
- 《秩序，从混沌中诞生》：简明的局部规则反复运行，形成复杂结构。
- 《无限的房间》：旅馆编号重新排列，不断空出新的房间。

### 12.2 底部文字如何编写

参考片使用的是**短句点题**，不是全文脚本贴屏。原创作品建议：

- 规则介绍：8–18 个中文字符，必要时拆为相邻两屏。
- 结论：6–16 字，优先有转折感或意象。
- 文献引用：可以稍长，但要延长画面停留且不能与高强度动画叠加。
- 不要用“你知道吗”“震惊了”“万万没想到”来做声量补偿。
- 文字入场晚于视觉主体 0.2–0.8 秒，让观众先看见现象。
- 最终强调字可以一词变金，例如“规律”“选择”“时间”。

### 12.3 无旁白故事脚本模板

```text
主题关键词：
片名隐喻：
开场具体物体：
观众原始直觉：
打破直觉的事件：
历史中的第一次尝试：
可演示的规则：
中段复杂化或反例：
最大规模的实验：
形态揭示：
首尾呼应物体：
结尾一行文字：
```

**注意：** 如果任何一幕必须靠三句话解释才能看懂，优先重做动画/实验设计，不是把三句话挤到屏幕上。

## 13｜片中的“高级感”细节逐项拆解

### 13.1 几乎所有大元素都靠**细线结构**托住

- 时间轴、图表、文献框、实验器物骨架都多用细描边，不用大面积彩色实心框。
- 描边的明度比核心数字低至少一档，让观众注意力自然落到数值。
- 细线本身可以轻微发金光，但不得变成霓虹灯管。

### 13.2 它让**物件材质**与**抽象图形**互相切换

- 骰子是具象 3D；概率树是抽象数学线条；人口记录是纸张；高尔顿板是器械。
- 这四类在同一审美系统里没有冲突，因为光、色、文字、速度和纹理统一。
- 新工程不要把所有素材都变成相同的扁平 SVG，也不要每一幕都用 AI 生成照片。

### 13.3 光不是平均照亮画面，而是“用光告诉观众哪部分重要”

- 白色骰子可成为纯黑里唯一显眼的体积；背景保持安静。
- 统计图在结果尚未出现前保持暗；达到临界时曲线或数字亮起。
- 片名的金色有仪式性，所以普通章节标题不应同样亮。

### 13.4 色彩具有语义

- 金：核心发现、数学趋势、历史主线。
- 骨白：客观物体、可读文本与样本。
- 暗红：少数对照结果、重要标记或印章。
- 黑/深蓝：巨大未知、时间深度和未被解释的背景。

### 13.5 用“一致的排版”连接“完全不同的实验”

每个镜头的主体都可能换，但左上的年份、右上的文献和下方短句不断复现。因此内容丰富却不显散乱。这实际上是一种**克制的片中视觉导航系统**。

### 13.6 使用历史年份，让节奏拥有“不可逆的方向”

观众不是任意看 12 个知识点，而是在沿着人类认知发展的时间方向前进。即使没有讲解，年份跃迁也能暗示故事正在走向更成熟的理论。

### 13.7 最强镜头不是最复杂镜头

- 只要 9 与 10 两列骰子组合能够正确累计，画面就很抓人。
- 一条线从剧烈波动趋于稳定，比十种随机粒子特效更能吸引注意。
- 一个个小球掉进槽里，比动辄铺满星云更能兑现“形状”的主题。

### 13.8 有“展示数字的美”，而不把数字做成仪表盘

年份、统计量和数学式本身成为摄影主体：大数占据画面空白，细小注释环绕它；没有网页按钮、卡片标题栏、品牌色进度组件。

### 13.9 温柔、缓慢的背景运动承担生命感

暗色粒子轻微漂浮、器物轻转、镜头弱推，保证停顿不会显死。**背景不能抢走实验动作的注意力。**

### 13.10 结尾有明显“回头看”的价值

看到最后的骰子，观众脑海中会自动叠上前面学到的分布、概率和规律。这种回扣是全片最值得借鉴的叙事设计之一。

## 14｜声音与音乐：如何学节奏，但不假装拿到了原始音轨

### 14.1 可确定与不可确定的部分

- **[M] 确定：** 文件中存在双声道 AAC 音轨，正片为音乐/声音配合的视觉叙事。
- **[O] 结构：** 无需口播，画面底部有可承担说明功能的文字。
- **[I] 推断：** 视觉高潮（标题、统计形状出现、数值揭示）很适合与音乐重音和 SFX 同步。
- **不可从成片唯一还原：** 原作者使用哪条音效、是否使用外部编曲、原始音乐 BPM、混音轨数、压缩链路及单独 SFX 文件。

### 14.2 建议新项目采用分层声音设计 [R]

```text
BGM：由创作者自行授权并在后期加入，Remotion 不强依赖它
SFX A：微机械（滴答、轻金属、木质器物、纸页）
SFX B：材料（骰子翻滚、金币落桌、滚珠碰撞、投针落下）
SFX C：数据（微小点亮、计数、线条延伸、结果出现）
SFX D：转场（低频过渡、短 whoosh，低使用频率）
AMB：低强度空间/空气底噪（可开关）
```

### 14.3 音效与画面事件对齐表

| 视觉事件 | 推荐 SFX 感觉 | 频率控制 |
|---|---|---|
| 初次物体入场 | 极短低频空气声/轻触感 | 每幕一次以内 |
| 年份跃迁 | 极轻机械刻度或纸页感 | 不每年都发声 |
| 抛骰/落针/落球 | 材质符合物理预期的碰撞声 | 按密度选取性播放，不为每个粒子播放 |
| 统计曲线渐进 | 细密、渐密的软颗粒声 | 只在主过程较明显时使用 |
| 关键数字揭示 | 一个低频厚度 + 清脆微高音点 | 最强结果才使用 |
| 文献/书信段 | 纸张翻动、柔和房间感 | 减少以便视觉换气 |
| 片名回归 | 精简尾音/空间混响 | 留出音乐收束空间 |

### 14.4 具体音频交付策略

- 输出 `final_no_bgm.mp4`：画面 + 全部必要 SFX，但**不带版权音乐**。
- 输出 `sfx_stem.wav`：单独完整长度音效轨，方便后期配乐和调音。
- 输出 `final_silent.mp4`：可选全静音母版，便于后期自由重组。
- 保存 `sfx_cues.json`：每个音效 `{id, startFrame, endFrame, gain, asset}`。
- 对过多重复事件（成千上万个滚珠/粒子），以“**稀疏实际碰撞 + 密集抽象纹理层**”混音，避免峰值爆炸。
- 最终配乐需要检查授权。参考片的相同配乐可以作为**私下节奏参考**，公开传播前确认使用范围；不能默认因其出现在参考片就可转载。

### 14.5 如果要做到真正逐拍同步

先对准备合法使用的音轨做**离线**节拍/重音分析，保存 `beatmap.json`（时间以秒、帧或统一的 sample offset 表示），再以关键重音对齐：

- 主标题显现；
- 章节年份跃迁；
- 实验开始；
- 数据达到结论；
- 终章回归。

不要让所有闪光、落球、字幕同时追同一个鼓点，应该保持**强弱层级**。若后期才添加音乐，可在视觉剪辑处设置 `musicAnchor` 标记，并交付一份时间码表。

### 15.2 先做设计系统，再做一个复杂场景

智能体交付的第一版不应是完整 120 秒，而应是同时包含以下五种元素的**小段高质量样片**：

1. 左上年份；
2. 右上真实历史文献；
3. 中央有“真实规则”的物理或数学图形；
4. 底部一句说明；
5. 暗色纹理、暖金材质、恰当音效。

**如果这个场景还像 PPT，整片做完也不会高级。**

### 15.3 Remotion 时间必须由帧确定

- 统一使用 `useCurrentFrame()`、`useVideoConfig()` 获取时间，运动量由帧或预计算状态计算。
- `spring()`、`interpolate()` 处理视觉进出，复杂物理过程采用确定性数据。
- 在 React render 中不要使用无种子的 `Math.random()`、`Date.now()` 或网络数据。
- 离线模拟生成固定数据，再按帧查表，确保首帧预览、任意帧截图和并行渲染一致。
- 若使用 Three.js / Canvas，保持 deterministic 并严格按相同 frame index 渲染，不依赖真实时钟、requestAnimationFrame 自驱动状态或实时交互帧差。

### 15.4 数据结构示意

### 15.5 动画属性的核心准则

**差的做法：** 每个元素都用随机缩放、飞入、闪烁，名为“高级动效”。

**好的做法：** 每个动效都来自场景的因果结构，例如：

- 时间线的年份沿时间轴平滑推进；
- 统计点因为实验发生而进入对应容器；
- 曲线在出现数据之后才继续延伸；
- 柱子的高度来自累计计数；
- 选中的路径亮起，未选中路径逐渐暗去；
- 片尾最初的实体重新出现，并叠上新理解的图形。

### 15.6 SVG / Canvas / Three.js 如何分工

| 内容 | 推荐 | 原因 |
|---|---|---|
| 年份、短句、文献 | DOM + SVG 辅助 | 字体清晰、可排版，便于 Remotion 定位 |
| 线条、概率树、简单图表 | SVG | 矢量锐利，路径和描边动画直观 |
| 几千至几十万粒子 | Canvas 或 GPU/WebGL | 避免单个 React DOM 节点过多 |
| 骰子、金属器械、深度镜头 | Three.js / 预制模型 | 真实体积、材质、高光与姿态 |
| 实拍/古籍来源素材 | 图像贴图或合法视频资源 | 真实年代肌理与文献细节 |
| 复杂物理实验 | 先离线计算，再渲染 | 科学可复现、任意帧稳定 |

**原则：不用为了展示技术栈而硬加 3D。** 参考片最有效的多数实验其实是 2D 数据可视化。

### 15.7 一致的镜头系统

推荐统一 `CameraRig` 与镜头配置：

```ts
type ShotCamera = {
```

## 16｜一次原创项目的完整生产流程（交给 Agent 的执行顺序）

### 阶段 0｜素材确认与观察记录

输入：原片视频、主题、目标时长、比例、版权约束、用户想保留的美术语言。

任务：

1. 用 `ffprobe` 读取真实元数据。
2. 抽帧生成故事板，至少覆盖开头、每个章节、主要视觉峰值、片尾。
3. 记录原片的布局、颜色、材料、过渡方式。
4. 输出 `reference_analysis.md`，明确哪些是观察，哪些是技术猜测。
5. 不复制参考片水印、平台包装或专属文案。

验收：**Agent 能用自己的语言说明原片“如何让实验发生”，而不只是说“黑金、高级、有粒子”。**

### 阶段 1｜科学内容与文案设计

1. 确定一个可具体化的片名隐喻。
2. 精选 3–8 个知识节点（数量取决于主题，不机械套原片）。
3. 为每个知识点写清**假设、规则、实际结果、边界**。
4. 核实所有文献、人物、年份、公式与数字，记录来源。
5. 设计无旁白的底部短句与少量说明文字。
6. 用 `content_validation.md` 记录每个数值怎么计算得出。

验收：**不看视频时能解释科学事实；不看文字时能从动画看出主要过程。**

### 阶段 2｜静态美术定稿

必须先交付：

- 3 张关键风格帧：开场物体、核心实验、片尾回扣；
- 1 张统一版式规范图；
- 1 张配色/字体/材质板；
- 完整场景的关键 UI/科学图形组件示例。

验收：每张静帧都应像博物馆展陈或高端科学纪录片画面；**不得像 SaaS 产品后台、投影片或普通网页信息卡**。

### 阶段 3｜12–18 秒动态风格验证

从最能代表全片的实验挑一段，必须演示：

- 可信的物理或数值变化；
- 年份和文献层正常工作；
- 文字出现节奏；
- 镜头的明暗与动感；
- 真实的声音事件；
- 1920×1080 下的字体和线条完整性。

验收：这段静音观看也能理解发生了什么；加 SFX 后丰富但不喧宾夺主。

### 阶段 4｜逐章生产

- 为每一章建立 **起点 / 演化 / 终点 / 转场接口**。
- 所有数字、曲线、粒子落点写入确定性数据。
- 避免不同章节各自发明一套标题或光影系统。
- 每完成一幕截取首、中、末三帧，并自动验证有没有遮挡、裁切、消失文字。

### 阶段 5｜声音与剪辑

- 用 `sfx_cues.json` 对齐声音与视觉事件。
- 先完成无 BGM 版本；保留后期音乐节奏点。
- 如果用户提供有授权的曲目，进行节拍匹配，再优化主要视觉高潮对位。
- 检查尾部留白、声音峰值、不必要的同频堆叠。

### 阶段 6｜渲染与 QA

- 确认全片无浏览器运行时依赖、无不可重复随机动画。
- 渲染全片，抽检至少 **每 1–2 秒一帧**，转场两侧额外检查。
- 检查科学数值与文字；对关键模拟做单元测试。
- 验证时长、声画同步、字体回退、对象出框、颜色突变、音效过响、黑场长度。
- 输出 MP4、SFX WAV、源码、使用说明、素材与引用清单。

## 17｜可直接执行的视觉质量验收表

推荐 100 分制，低于 **85 分不得作为正式成片**。此量表是新项目的评审工具，不是对原片的客观评分。

| 指标 | 权重 | 通过表现 | 典型失败 |
|---|---:|---|---|
| 叙事和片名隐喻 | 15 | 首尾呼应，核心意象被视觉兑现 | 片名只出现在开头 |
| 理论/实验可理解性 | 20 | 看得出条件、过程、结论 | 只有概念名和漂亮图形 |
| 黑金美术统一性 | 15 | 暗部克制，光与色有重点 | 全屏金色、霓虹或配色漂移 |
| 历史/文献信息完整度 | 10 | 真实、统一、与章节相关 | 编造文献、乱码、花哨装饰 |
| 动画真实性与精度 | 15 | 有连续过程，结果来自计算 | 硬切假结果、随机乱飞 |
| 排版与信息节奏 | 10 | 字可读，有留白，主次明确 | 满屏小字、频繁弹窗 |
| 物体/材质与镜头 | 5 | 器物可信、材质协调 | 塑料感、无理大旋转 |
| SFX 与剪辑 | 5 | 声画一致，保留安静时刻 | 粒子每碰撞一次就爆音 |
| 工程可维护/可复现 | 5 | 场景、数据、样式分层 | 所有代码写一个文件、随机不可复现 |
| **合计** | **100** | | |

### 17.1 一票否决问题

以下任意一项发生，优先修复而不是继续加特效：

- 科学结论、年份、模型条件有明确错误或无来源虚构；
- 主要实验无法说明数据来自哪里；
- 字体乱码、文字消失、图表坐标错误、数据超界；
- 一半以上场景仍像 PPT 页切换；
- 旁白/字幕/音乐设置违反用户确认的制作要求；
- 抄用了参考片的专属素材、配乐或显著镜头编排；
- 只有预览，没有实际交付最终可播放 MP4。

### 17.2 静帧审查清单

- 是否大面积是舒适的深暗空间？
- 主体是否一眼能识别？
- 年份/文献/字幕是否有稳定位置？
- 当前最重要的数字是否最亮？
- 是否有多余 UI 卡片、按钮、图标？
- 细线是否足够锐利，粗细统一？
- 除引用历史文献外，是否缺少真正的“材质”？

### 17.3 动态审查清单

- 第一次观看时能否追踪主体运动？
- 前一帧动作是否导致下一帧结果？
- 变换是否有不必要的乱弹、乱抖、突然变速？
- 曲线/统计量能否复算？
- 字幕出现时主体有没有减速或让位？
- 最亮画面是否留给知识结果，而非装饰？
- 转场是否服务时间/因果关系？

## 18｜反例库：最容易被智能体做坏的 16 件事

1. **把“黑金”理解成黑底金边卡片。** 参考片的关键不是卡片，而是器物、实验与学术展陈。
2. **满屏漂浮粒子。** 参考片大多数背景非常安静，粒子是空气感而非主角。
3. **每段都出现同一种强光爆炸。** 片名和实验终点才该有峰值。
4. **历史年份像 PPT 章节标题。** 它应该像持续存在的坐标轴与档案索引。
5. **公式多却没推导过程。** 学术感≠公式密度。
6. **让各种理论镜头都用科技网格。** 应按知识形态选择器物、曲线、地图、分布、文献。
7. **器物像廉价贴图。** 没有真实体积、光影和材质的骰子会拉低高级感。
8. **只设计一张好看的封面。** 镜头内部的动画与数据没有设计，结果只是图文轮播。
9. **一切匀速线性移动。** 动画需要符合物理/认知节奏，有建立、积累、揭示和停顿。
10. **所有文字大小相近。** 年份、实验数值、学术注释、底部文案必须有严格层级。
11. **使用红蓝紫赛博霓虹。** 会破坏参考片的历史科学气质。
12. **用现代 UI 命名元素。** “Dashboard, KPI card, Button, Tooltip” 等视觉惯性会把影片做成产品演示。
13. **不维护全片统一色表。** 不同场景由不同 Agent 生成时极容易风格漂移。
14. **堆积不可信的科学符号。** 任何图形要能解释它为何出现、代表什么。
15. **先做完整 2 分钟再看质量。** 应先做最难的核心实验风格测试。
16. **把水印、平台结束页也当作可学习的设计。** 这是平台包装，不是原片高级感来源。

大型视觉工程最怕模型在同一轮同时做研究、文案、UI、粒子、音频和渲染，最后每部分都粗糙。推荐以下工作包：

## 22｜技术验证案例：用真实数据复现一种视觉过程

### 22.1 高尔顿板 / 伯努利试验的决定性原则

假设一个对称模型，每颗球经过 `n` 层时，每次向左/向右的机会相等：

- 终点槽位编号由向右的次数决定；
- 一批球的落点构成离散频数分布；
- 中央附近槽位往往更常出现；
- 随着样本量变大，柱状频数轮廓逐渐稳定。

**模型必须明确是“对称独立抉择模型”，还是“带碰撞与弹跳的近似物理模型”**。两者可以做出相近形态，但不是同一个求解过程。

### 22.2 参考的代码设计（伪码）

```ts
const rand = seededPRNG(seed);
const balls = Array.from({length: count}, (_, index) => {
  const choices = Array.from({length: rows}, () => rand() < 0.5 ? -1 : 1);
  const rightCount = choices.filter(x => x === 1).length;
  return {index, choices, rightCount};
});

const bins = new Array(rows + 1).fill(0);
for (const ball of balls) bins[ball.rightCount]++;

// 真实渲染中：按帧逐个或按批次揭示 ball，
// 底部柱形数量来自同一份 bins 的逐步累计值，
// 不独立硬编码一条“像正态分布”的曲线。
```

**这种物理/数据一致性，才是“让规律可见”的本质。** 不必非得复刻参考片的高尔顿板，新的社会、心理、经济模型也能按同样原则制作。

## 23｜原创改造公式：怎样保持相同高级感而不是复刻？

### 23.1 允许保留的“通用制作语法”

- 深黑暗场与克制的金色重点；
- 古典/历史科学的衬线数字、边注、文献排版；
- 历史推进的宏观节奏；
- 可视化实验从少量结果增长到总体规律；
- 稳定四区版式；
- 精密几何图形 + 有材质的少量具体物件；
- 很少的屏幕说明文字；
- 首尾呼应的抽象意象。

### 23.2 应该改造的专属内容

- 主片名、开头实物和结尾物体；
- 学者/文献/年份的具体排列；
- 数学实验的顺序和视觉隐喻；
- 标题具体文字设计、装饰纹章和画面运动曲线；
- 背景音乐、音效素材和商标水印；
- 镜头中的独有构图与视觉组合。

### 23.3 三个原创应用示范

**《时间并不均匀》**：一只精密时钟分为两条实际走时路径；地表与高处对照；原子钟实验记录；再把视觉语言从仪器移到人类主观时间感受。注意物理时间与心理知觉属于不同机制，不用错误类比硬接。

**《看不见的代价》**：用 19 世纪经济学文献作历史开头；一枚金币进入两条互斥的路径；观众看到被选择的一条越来越亮，另一条未被选择的可能性逐渐消散；再通过折现/沉没成本对照，使“代价”成为真正被看到的对象。

**《秩序，从混沌中诞生》**：从古典规律观念进入细胞自动机；让看似无意义的网格按真实规则演变为滑翔机和复杂结构；最后由一个微小局部模式演化成宏观图形。画面必须严格基于生命游戏规则。

## 24｜最终“一页纸检查表”——其他模型读完全文后必须记得

**风格**

- [ ] 黑色占据绝大部分画面；金色只标重点。
- [ ] 左上大年份，右上真实文献，中央实验，底部短句。
- [ ] 年份、数字、字体、线条与器物属于同一美术系统。
- [ ] 羊皮纸主要作为文献物件或低强度肌理，不铺满全片。
- [ ] 没有彩色卡片、现代 dashboard、卡通按钮和塑料质感。

**知识**

- [ ] 每段有疑问、可见的规则、动态结果和简洁解释。
- [ ] 数据由真实模型生成，且可复核。
- [ ] 历史人物、年份、文献及引文可查。
- [ ] 不是为了数量机械塞理论；章节之间存在认知递进。

**镜头**

- [ ] 一个镜头有唯一视觉重点。
- [ ] 精彩的是图形从无到有，而不是每秒强光闪烁。
- [ ] 高能过程后有能读字的停顿。
- [ ] 主片名首尾出现，最后与开头物体构成意义闭环。

**声音**

- [ ] 不依赖旁白。
- [ ] SFX 来自可见动作，不过度堆积。
- [ ] 可导出无 BGM 成片和独立 SFX stem。
- [ ] 不擅自复用参考片配乐。

**工程**

- [ ] 16:9、1920×1080、30fps。
- [ ] 使用 frame-driven、确定性模拟。
- [ ] 有 12–18 秒精制样片和三张关键静帧。
- [ ] 有完整成片 MP4、源代码、科学验证和 QA 报告。
- [ ] 清楚区分参考原片的**可观察事实**与本文的**推荐实现方式**。

## 25｜最终结论：这个参考片最难复现的是什么？

**不是粒子，不是金光，也不是 Three.js。**

它最难的部分是：**对每个知识点都找到一种“看着就能懂”的物理形状，并且用统一的历史纪录片语言让所有形状连成一条故事线。**

当观众从骰子走到概率树、抽样、曲线、投针与滚珠板，再回到最初那枚骰子时，真正完成的是一次**认知变化**。

因此，对于 Codex、Claude Code、Astra 或任何未来模型，检验它有没有理解这部片，不应该问“能否生成黑金科学动画”，而应该问：

> **能否选择一个真实而有价值的科学问题，在没有旁白的情况下，让观众亲眼看见一个规律从实验里出现，并通过严谨的图形设计、美术、镜头与音效，把这个过程拍成值得反复观看的短纪录片？**

如果答案是能，便已经真正学到了这部参考片最重要的制作方法。

### 附记｜科学史内容谨慎使用

本报告中的年份、人物、书名、数值是对**参考视频画面组织方式**的观察，并非对其所有历史叙述作了独立学术核查。原片有些年份以过渡动画呈现，不能从中间帧推断具体出版年；个别中文归属与科学史通行表述也可能需要核实。新项目上屏的每一处历史/科学信息，都应另外完成来源验证。

### 附记｜与其他项目的关系

此文档是**跨项目风格指南**，可用于个人账号的「理论视觉纪录片」系列；不等于「如果放映局」的生活脑洞动画通用风格。生活脑洞动画应按各自选题选择主视觉体系，不能强行套用历史纪录片黑金设计。
