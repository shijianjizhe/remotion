## 分析结果

- 来源：用户提供的《音乐.mp4》中的 AAC 音轨；提取到 `music.m4a` 没有重新编码，不等于“原始录音无损母带”。
- 时长：192.842 s。
- 速度：**约 112.798 BPM**，单拍 **0.531926 s**，4 拍约 2.128 s。
- 拍网格起点：**0.4376 s**；原文件截取、混音或声画剪辑时，请验证是否需要调整音轨起点。
- `beatInBar` 按 4/4 编排假设赋值，不意味着对音乐拍号、真正每小节第一拍进行过人工听辨验证。
- 节拍格由自动检测整体拟合；鼓、军鼓、合成器冲击和高频填充可能发生在半拍、切分或拍点之前；请不要把所有峰值当“强拍”。

## 文件用途

- `music.m4a`：可放在 `public/audio/music.m4a`，Remotion `<Audio>` 载入。
- `music-beatmap.json`：完整拍点网格、分段、精心挑出的 20 个视觉提示点、30/60 FPS 对照。
- `remotion-beat-sync.ts`：基于绝对音轨时间而非固定帧数算节奏；支持选曲偏移。
- `BeatSyncedExample.tsx`：30 FPS 示例，展示 Remotion 无旁白、按音乐卡点的反转数字画面，命中帧立即产生缩放。
- `sfx/impact.wav`、`sfx/tick.wav`、`sfx/whoosh.wav`：自行代码合成的轻量原创示例音效，用于试混，可替换更专业的授权音效。
- `智能体执行说明.md`：可以直接复制给编码智能体的完整执行指令。

## 卡点美学约束

1. **大爆发（drop 5级）**：音前约 8–12 帧缩小/蓄力，命中帧瞬间展开，随后 8–12 帧回弹；同步一层低音冲击 SFX。
2. **音色变化（4级）**：场景层级、镜头距离、文字布局改变，避免常规闪白。
3. **Fill 密集音（3–4级）**：每个关键瞬态让局部图形、数字、线条跳动 2–4 帧，切忌整屏频闪。
4. **普通节拍**：只需小幅透明度/线宽/背景颗粒的细微呼吸（如 1.00→1.02），不一定都动。
5. **85.5–102.6s 的收敛段**：主动减少特效，这样 102.57s 才会令人惊讶。
6. **音频时间对齐**：如果从原曲 17.459s 开始用，Remotion `<Audio startFrom={Math.round(17.459*fps)} />`，所有事件都用 `frame = Math.round((timeSec - 17.459)*fps)`；不要仍用原曲 524 帧作为剪辑后的出现位置。
7. **横屏**：1920×1080，视觉保持参考片的黑金、细线、留白、科学图表与清晰少字；不要用满屏花哨打击效果。

## 使用方式

复制 `music-beatmap.json` 到项目 `src/data/`，`remotion-beat-sync.ts` 放进 `src/utils/`，`music.m4a` 放进 `public/audio/`。TSX 示例里的 import 路径可根据项目结构调整。数据包内提供自行合成的 `whoosh`、`impact`、`tick` 占位音效；试混时把音量压低，不要把背景音乐内已有的鼓点再叠得过重。实际成片也可以替换成更专业的有授权音效。
