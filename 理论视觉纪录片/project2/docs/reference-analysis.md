## 归纳出的视觉规律（本片采用）
1. **色彩**：近黑底（非纯黑）+ 暖棕中心晕；金色只用于年份、关键数字和关键词；赭红只在“失败/偏差”时出现。
2. **版式秩序**：上缘 = 历史锚点（年份 / 文献），中间 ≈ 65% = 实验主体，下方 = 一句结论。一屏只有一个实验。
3. **推导感**：图形是在镜头里逐步“长”出来的（分支生长、粒子累积、曲线收敛），而不是一次性出现。
4. **字幕**：宋体，字距较宽，出场时从模糊变清晰；关键词换成金色。
5. **景深**：前景有稀疏、虚焦的金色光点；背景有极轻的纸张肌理和暗角。
6. **转场**：多数是“暗场 → 新的年份”，节奏平稳；关键结论出现前常有短暂停顿。
7. **首尾呼应**：开头的骰子在结尾再次出现。

## 本片的差异化处理（不逐镜头照搬）
- 母题从骰子换成**古典机械钟**；首尾都以同一只钟面和外圈刻度闭环。
- 转场按 PRD 要求由物体驱动：钟阵 → 世界线 → 等势线 → 地球航线 → 卫星轨道 → 虹膜 → 记忆碎片 → 钟面。
- 参考片里的卡片对比只在 GPS 读数这类必要场合以“细线面板”出现，避免网页卡片感。
