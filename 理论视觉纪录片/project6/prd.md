## 0. 你的身份与最高优先级

你是本片的**导演、科学内容编辑、视觉设计师、动效设计师、剪辑师和声音设计师**。你拥有实现方案的自由，但必须遵守以下创作结果约束。

**最高优先级依次为：**
1. **科学准确**：实验条件、时间、百分比、单位、结论均与原始研究一致；视觉隐喻不得伪装为真实实验录像。
2. **音乐驱动的音画同步**：先读取用户提供的**配乐文件和配乐分析文档**，制作音乐时间轴，再决定镜头起止、动作峰值、读数抵达和转场时机。尽量让每一个有意义的动作落在真实音乐节奏点上。
3. **运动与信息接力**：必须让“**实验动作 → 读数 → 短字幕 → 镜头推进**”轮流接棒，而非所有信息同时拥挤到屏幕上。
4. **《运气的形状》式视觉纪录片表达**：延续参考片的叙事语法、科学可视化质感与音乐节奏哲学，但创作原创镜头，不照搬它的画面、版式或资产。
5. **完整性与节奏**：视频要有起承转合和完成的结尾；任何镜头完成有效动画后都不应无谓静止。

**创作边界：**不使用旁白；不以人物演戏、悬疑短剧、假想剧情作为主轴；不是 PPT 翻页科普；不是单纯的卡点特效合集。全文旁白为零，信息由实验过程、精密读数、简短字幕、画面内逻辑及音乐完成。

## 2. 一句话创作目标

**同一段事件，只换了提问中的一个词，记忆中的速度和细节就可能改变；而即使没有人误导，我们也可能“记起”从未出现的词。**

全片提出三层递进的问题：
1. **为什么同样的事故，会被估计出不同的速度？**
2. **为什么原本没有玻璃的影像，有人回忆起了碎玻璃？**
3. **为什么从未播放过的一个词，也会被一部分人认为自己看见过？**

影片的思想不是“人类记忆完全不可信”，而是“记忆通常有用，但回忆并不是对过去的无损播放；清晰和确信都不构成独立的真实性证明”。

**主标题：**记忆会撒谎  
**英文小字：**THE MEMORY LIES（可选）  
**建议总时长：**100–130 秒，以实际配乐乐句长度为准；如果音乐结构确实支持 133 秒，允许在这个附近成片。不要为了凑时长留下空镜头。

## 3. 参考片必须学什么、不学什么

### 学习的创作机制
- **暗场中呈现一个真实问题**：单点照明、深黑留白、精密历史档案质感。
- **抽象理论有可触摸的物理载体**：胶片、轨迹、速度标尺、数据轴、答案标记、时间轴、语义节点、记忆碎片。
- **历史实验逐步演化为可视化证据**：画面不是“配插图”，而是亲自展示变量、对比、测量和结果。
- **连续变形和空间递进**：一条路径变成刻度；刻度成为数据柱；数据柱转为胶片；胶片破碎后重组为记忆档案。
- **音乐控制运动的轻重缓急**：节奏与知识揭示协同；高潮落在关键结果被揭示的一刻。
- **画面文字少而准**：一屏只承担一个主要信息任务，严禁大段论文文字。

### 不要机械模仿
- 不得复制参考片里的独有镜头、素材、具体版式或镜头序列。
- 不得为“像参考片”而重复它的内容结构；本片的核心视觉装置应该是“记忆被语言和联想重构”。
- 不要全程一成不变地用金色粒子轰炸；应通过疏密、大小、亮暗、速度建立层次。

### 统一视觉方向
- 背景：深黑／近黑，偶有极低对比度纹理。
- 主高光：低饱和暗金、暖白；必要时用少量冷白或灰蓝区分“原始记录”与“后来输入的信息”。
- 材质：老式实验胶片、微光档案纸、玻璃、精密刻线、科学仪表的混合质感。
- 图形：极细线条、圆环／弧线、运动轨迹、数字刻度、信息节点、胶片孔、时间轴。
- 摄影语言：中远景建立场景 → 局部推近 → 微观变量变化 → 极近处读数 → 后撤揭示系统关系。
- 文案：中文为主；英文字母用于实验原词、论文年份、单位和小型标注。
- 审美：高级、克制、清晰、可信。不要廉价科技 HUD、渐变大字报、滥用霓虹与泛光。

## 4. 剧作结构：五段式，并非死板秒表

以下区间为**剧情比例和信息顺序示例**；真正镜头时间**必须经配乐分析后调整到小节、重拍、过门、停顿和音色变化处**。禁止先死锁 0:00–0:XX 再让音乐勉强适配。

### 第一幕｜1974：事件被记录（约 0–18%）

**目标：**在历史实验语境中建立“真实发生过的影像”和“后来提出的问题”这两层。

预期接力：
1. 黑场中的 `1974` 以极简方式显现；老式放映机转动，光束切开黑暗。
2. 胶片中出现**示意性的汽车碰撞**，车身轨迹可被几何抽象替代；明确标记 `SCHEMATIC RECONSTRUCTION / 情境重现`，不得声称生成场景是原始实验影像。
3. 减少背景细节，汽车轮廓抽象为两条运动轨迹，在某个节拍位置交汇。
4. 接下来出现实验问题，两个条件的区别仅在动词 `HIT` 与 `SMASHED`。
5. 把不同动词变成可观测的“实验变量”：词语卡片就位，画面准备进入测量。

**禁止：**长时间停留在漂亮的放映机或汽车照片上却没有新的理论信息。

### 第二幕｜一个词，改变读数（约 18–39%）

**目标：**让观众清楚看懂“提问措辞影响速度估计”，不是让读数成为无意义装饰。

原始研究实验一中不同措辞对应的平均速度估计：

| 英文动词 | 平均估计速度（mph） |
|---|---:|
| smashed | **40.5** |
| collided | 39.3 |
| bumped | 38.1 |
| hit | **34.0** |
| contacted | 31.8 |

主镜头优先聚焦 **HIT = 34.0 mph**、**SMASHED = 40.5 mph**，在完成主要对比后，可用精细刻度补充其他条件，但不要因展示全部数字而造成认知负担。

**严谨提示：**40.5 与 34.0 是**不同受试者组的平均速度估计**，不是车辆真实速度，也不是同一个人的记忆从 34.0 变成 40.5；在字幕小字中准确标注“平均速度估计 / mph”。

接力范例：汽车轨迹冲撞（实验动作）→ 速度轴展开（测量）→ 两组数值分别滚动到 34.0 和 40.5（读数）→ 极短字幕“只换了一个词”（解释）→ 镜头沿数值差转入记忆档案（推进）。每一环都尽量落在听觉节点上。

### 第三幕｜七天后：不存在的碎玻璃（约 39–62%）

**目标：**第一大科学证据高潮；直觉冲击高于第二幕。

原始研究实验二：150 名参与者，三组各 50 人；在**一周后**的提问中，研究者问“是否看到碎玻璃”，而影片中实际**没有碎玻璃**：

| 实验条件 | 回答“看到了碎玻璃” | 比例 |
|---|---:|---:|
| smashed | 16/50 | **32%** |
| hit | 7/50 | **14%** |
| control | 6/50 | **12%** |

**务必分清：**上述比例出自**实验二**；第二幕的 40.5 与 34.0 mph 来自**实验一**。不能画成“同一批人先给出 40.5/34.0、再过一周回答玻璃问题”的连续追踪流程。可以用“实验一 / 实验二”微标签及场景切换区分。

接力范例：实验一的数据线折叠收纳 → 新的实验二胶片进入 → 7 DAYS LATER 时间刻度加速走过 → 三组档案分列 → `32% / 14% / 12%` 逐组在重拍抵达 → 观众短暂停顿理解“原片无碎玻璃” → **原本完整的胶片中浮现一片金色虚构玻璃** → 下一次强拍整片裂成三组“回忆版本”。

**特效解释边界：**视觉上的碎玻璃从无到有，是对实验结果的**抽象隐喻**；不能把动画当成真实受试者在脑中“看到”什么的证据。

### 第四幕｜1995：没人说过的词（约 62–83%）

**目标：**升级命题：即使没有误导性提问，联想和语义关系也可能促使人想起未呈现的词。

以 Roediger & McDermott (1995) 的 DRM 词表范式为科学依据。可展示一组**与“睡眠”相关的中文演示词语**（如“床、休息、醒来、做梦、困倦……”），但**必须说明是中文视觉示例，并非原实验逐字中文材料**。中心词 `睡眠` 不在已展示的词表里。

- 多张词语卡按音乐脉冲快速有序进入，留下足够可读的时长。
- 每个词连出细线，语义网络自然围出一个“缺席的中心”。
- 镜头推进到空中心位置，中心词 `睡眠` 自行亮起，但随即标注：**“它从未出现。”**
- 可用原论文某个实验的具体结果作为统计证据（实验一 40% / 实验二 55% 的关键诱饵词虚假自由回忆率），但**不得把这些原实验英文材料的百分比直接归于自创中文词表的观众实验**。若为避免解释负担，可只在学术小注中注明，核心画面专注演示原理。

这段应突出“错的东西如何被补齐”，而不是再重复上一幕的碎玻璃戏法。

### 第五幕｜回忆不是播放，而是重建（约 83–100%）

**目标：**将两个实验统一为一个强有力、可视化且不夸大的结论。

- 先前的汽车、动词、读数、碎玻璃和词语节点以快速而清楚的方式重新入场。
- 这些元素围绕一个不断演化的“记忆档案”结构，开始重新组合。
- 可以通过一次漂亮的、由音乐顶点驱动的重构：同一份原始事件与一份有错漏的“记忆版本”同时呈现，两者几乎重叠，仅在关键细节上不同。
- 主文案依次出现（可根据实际构图微调）：
  - **“回忆，不是重播。”**
  - **“它也是一次重建。”**
  - 最后收束：**“清晰，不等于真实。”**
- 尾声留够观众读懂最后一句的时间，但绝不保留一段“所有东西都停了仍在干等音乐结束”的无效静帧。可通过最后的光线熄灭、档案闭合、微小残响与音乐余韵完成结束。

## 5. 最高优先级：音乐驱动的“动作—读数—短字幕—镜头”接力系统

这不是普通的“每隔 N 帧切镜头”。**所有主要视觉动作都应首先找到音乐理由。**

### 5.1 先做音乐地图，再做镜头

Astra 必须在真正搭建镜头前：
1. 读取用户提供的音乐分析文档，提取 BPM、节拍位置、重拍、过门、停顿、低频冲击、旋律断点、能量曲线、高潮区与结尾。
2. 亲自对音频进行验证：波形、瞬态、onset、节拍追踪、主观试听。**文档标注不是盲信的绝对真值**；若其时间戳与实际音乐冲突，以音频为准并说明原因。
3. 建立可核对的**Cue Sheet／音乐提示表**，每一个重要 cue 都有时间（秒／帧）、听觉事件、画面事件、信息目的和强度。
4. 先确认乐句边界和全片的三个冲击峰值，然后反推每幕时长；必要时合理剪辑音乐，但剪接必须听起来自然，不能粗暴掐断小节。
5. 保证音频与视频在最终帧时间线上同步；把音频播放起点、可能的前奏偏移、末尾收束写清楚。

**不要预设 BPM。**此前讨论过的任何 BPM 数字只能作为可能线索，必须由本次真正使用的音频核验。

### 5.2 每一个“卡点”应该卡什么

- **弱拍／细小击打：**胶片帧移动、微细刻度增长、数字个位变化、词卡入位。
- **标准拍：**实验变量切换、短字幕出现、读数阶段性停靠、轨迹方向变化。
- **重拍：**碰撞发生、`34.0`／`40.5` 数值最终锁定、实验结论揭示、`32%` 突出、缺席中心词生成。
- **过门／音色转折：**从实物抽象为线条、从第一实验转入第二实验、镜头穿过信息结构。
- **停顿／弱音：**让关键事实落地，例如“实际没有碎玻璃”“这个词从未出现”。必要时用一瞬间的声音空缺强化冲击。
- **最终高潮：**原始记录与重构记忆在同一个运动系统中汇合、对齐、偏离，再出现最终命题。

**要避免“卡点疲劳”**：不是每一个音符都做闪白、震屏、切镜头。细节跟随小节拍，主要事件跟随强重拍；在密集区安排运动链，在稀疏区给观众理解读数的时间。信息释放点比表面特效更重要。

### 5.3 接力法：四种动作轮流推动观看

每个 3–8 秒的微段落都应尽可能包含如下接力：

| 接棒 | 观众在看什么 | 典型行为 | 与音乐的关系 |
|---|---|---|---|
| A 实验动作 | “发生了什么？” | 汽车接触、单词进入、胶片推进 | 击打音／律动启动 |
| B 读数 | “发生了多大的变化？” | 数值增长、比例形成、时间刻度通过 | 逐拍累积，重拍锁定 |
| C 短字幕 | “这意味着什么？” | 一个词、短句、反常识事实出现 | 音乐弱区或重拍后的短空档 |
| D 镜头推进 | “接下来发生什么？” | 轨迹延伸、镜头穿过数字转入下一实验 | 过门、上升音、下一乐句起点 |

**同一段落尽量不要让四项同时开始。**上一项形成理解后，下一项接棒；可以有局部重叠，但必须有视觉主次。例如碰撞动作发生的瞬间，数值尚未占据主导；数值锁定时，字幕才接近出现；观众读完字幕，镜头才大幅推进。

### 5.4 微时间线示例（仅说明机制，不是固定秒数）

假设某乐句含 8 个强感知拍点：

`拍 1` 汽车轮廓入场 → `拍 2` 两车靠近 → `拍 3` 冲撞 → `拍 4` 速度轴延展 → `拍 5` HIT 数字增至 34.0 → `拍 6` SMASHED 增至 40.5 → `拍 7` 短句“只换了一个词” → `拍 8` 镜头沿差值进入下一场景。

**真实制作时需为字幕阅读和数据比较保留合理时长；不能为了追求“每拍一个字”牺牲可理解性。**

### 5.5 必须做音画检验

在初剪和终剪各自检查：
- 音乐重拍与关键动作峰值是否肉眼明显同步，而非差半拍。
- 快速数字增长是否在**落点**锁定，而非落点之后继续无意义拖动。
- 信息阅读时，背景运动是否主动降低干扰。
- 转场是否在音乐结构发生变化时推进，而非任意刷过。
- 连续两个镜头是否复用相同动效导致乏味。
- 是否存在“动画早已停止，音乐继续播放，画面空等”的问题。

## 6. 素材策略：12 个核心资产只是起点

建议规划 **10–12 个核心视觉资产／系统**、约 **24–30 个有独立信息贡献的镜头**、**3 个重要情绪／视觉峰值**。这些是创作目标，不是上限。材料不足以支撑高质量则可以增补，反之无需凑数量。

建议资产族：
1. 1974 年代实验室空间或档案氛围；
2. 老式放映机／胶片装置；
3. 抽象汽车碰撞示意及车身轨迹；
4. 可放大、可透视、可抽象的胶片序列；
5. HIT／SMASHED 实验变量卡；
6. 精密速度仪表与数据标尺；
7. 三组百分比／受试者点阵图；
8. 金色玻璃碎片及虚假细节生成系统；
9. 1995 词语卡片阵列；
10. 词语联想网络；
11. 记忆档案与信息重构装置；
12. 原始事件／回忆版本并置的终幕系统。

外部 AI 图片／素材尽量用于历史质感和无法高效程序化的实体镜头；**核心实验过程、数字、图形、轨迹与转场优先用可控制、可验证的程序化动画**。不为了追求“素材多”而制造切图感。

如使用 AI 生成汽车镜头、放映机或实验室，必须确保其只是**情境重现／视觉示意**；不把生成的历史图当成真实照片，也不滥用可识别的受版权保护影音资料。

## 7. 字幕、数值、科学内容与阅读节奏

- 字幕不担任旁白的全部职责。能通过车速轴、对照、时间标记、占比变化说清楚的内容，不再写成长句。
- 主字幕通常 4–12 个汉字；关键内容可有短句，但不要形成段落。
- 同一时间**只允许一个主结论**。实验名称、单位、样本量与来源作为二级辅助标签。
- 数值使用易读格式，锁点明确；mph 与百分比必须始终有上下文。
- 必须把**实验一**与**实验二**的样本及数据明确隔开；不能为了叙事“无缝”而偷偷合并研究条件。
- DRM 的中文词表是对范式的创意演示，**不能宣称对着本视频看词的观众已有研究中 40% 或 55% 的假回忆率**。
- 不能写“问一个词，就可以随意篡改所有人的记忆”；应采用“可能影响”“一部分参与者”等准确措辞。
- 不把“记忆重建”拟人化成真实脑内齿轮或唯一确定的脑机制。节点、档案、碎片是科学视觉隐喻。

建议重点字幕池（由导演根据配乐选择，不必全部用）：
- `1974` / `同一场事故` / `不同的问题`
- `HIT` / `SMASHED` / `平均速度估计`
- `只换了一个词`
- `7 DAYS LATER` / `一周之后`
- `影片里，没有碎玻璃`
- `1995` / `一个从未出现的词`
- `它从未出现`
- `回忆，不是重播` / `它也是一次重建`
- `清晰，不等于真实`

## 8. 三次高潮的分工与音乐结构

**高潮 1｜措辞改变估计值**  
强调精密、理性、数字的冲击。动作峰：两条速度估计最后一次锁定并形成 6.5 mph 的组均值差。不要误写成真实车速差或单个人变化。

**高潮 2｜不存在的玻璃**  
强调反常识与“不可能的细节”。动作峰：**原始影像没有碎玻璃**这一事实被确立之后，在错误记忆的可视化层中出现虚构玻璃。比高潮 1 更具视觉层次。

**高潮 3｜完整而错误的记忆**  
强调思想统一与情感余韵。动作峰：语义网络、实验结果、原始影像重组，形成两份“看似同样可信”但有差异的档案。最后文案在音乐收束处出现。

三个高潮不能都是相同的粒子爆炸：一为读数精度，一为视觉悖论，一为结构性重建。

## 9. 声音设计

- 以用户提供的配乐为**主音乐**。优先保持整体连续性，必要时进行经过听感验证的微编辑。
- 辅助音效只用于增强真实节拍与实验质感：胶片齿轮、碰撞的低频钝响、微小刻度点动、电子读数锁定、玻璃细裂声、词卡吸附、档案闭合等。
- 不要用音效轰炸掩盖原有音乐，避免每一次卡点都有巨大的 whoosh／impact。
- 音效应与画面动作起落同步，并服务于已分析的音乐重音。
- 控制音量动态；高潮有冲击，不等于持续满音量。输出前认真检查削波、突兀静音、尾声与开头响度。
- **无旁白、无 AI 配音、无人物对白。**

## 10. Astra 的制作工作流

**阶段 A：研究与准备**
1. 盘点全新工程中的视频、音乐、历史分析文档、配乐分析文档及其他资产。
2. 观看参考片，归纳可迁移的视听语言（镜头速度、镜头运动、信息密度、配色、材质、转场、高潮机制）。
3. 核对研究论文和每个要呈现的数字；保存来源清单。
4. 获取实际配乐的音乐地图：强拍、段落、停顿、高潮、时长。
5. 产出一个内部制作计划：总时长、章节、音画 cue sheet、预计镜头分布与素材表。随后直接推进制作，不要把计划当最终交付物。

**阶段 B：素材与动态系统**
1. 制作视觉资产、统一质感与字体体系。
2. 优先实现可被多镜头复用的实验装置、数字读数、档案、时间轴、轨迹与语义图形系统。
3. 逐个形成可被准确调度到音乐 cue 的运动过程。
4. 适时预览并修正遮挡、层级、中文字体、空间尺度与运动衔接。

**阶段 C：按音乐装配整片**
1. 优先把三个高潮落在配乐合适的强节点。
2. 补齐各高潮之间的动作—读数—字幕—推进接力链。
3. 保持一处完成有效运动，另一处就开始接棒，避免没有新信息的死时长。
4. 检查镜头语言连续性，并让每一次视觉转场有空间／叙事动机。

**阶段 D：完整审查与发布交付**
1. 渲染整片，并从头到尾看一遍；不要只验证片头几秒。
2. 抽查关键帧：开场、每个读数锁定、三处高潮、结尾。
3. 检查音乐与视频的对齐、字幕阅读时长、渲染异常、声音问题、科学标注。
4. 修复问题后再次输出最终版本。
5. 交付**最终 MP4**、必要源文件以及一份简洁的成片报告（使用的音乐文件、时长、分辨率、帧率、科学来源、关键 cue 和已检查项目）。

> 技术实现层面由 Astra 自主选择 Remotion 组件拆分、渲染方式、动画算法、3D／SVG／Canvas 技术与依赖。**不要为了服从某种预定代码结构而牺牲成片质量。**

## 11. 完成验收标准：以下全部必须满足

- [ ] 是一条完整、可直接观看和发布的横屏理论视觉纪录片，不是 Demo。
- [ ] 16:9 横屏；无旁白；符合本账号的固定高级视觉纪录片风格。
- [ ] 实际阅读并使用已有音乐及配乐分析；能提供可核查的强拍与关键画面对应表。
- [ ] 核心段落真正实现了“**实验动作 → 读数 → 短字幕 → 镜头推进**”接力，不是四种内容静态同屏。
- [ ] 大多数有意义的动作与节奏事件同步；三次高潮各有不同的视觉功能。
- [ ] 没有“动画停止后还无意义地停留很久”的镜头。
- [ ] 1974 年实验一、实验二分得清楚；速度数字、单位、碎玻璃比例正确。
- [ ] 1995 年词表演示不把演绎词表冒充原实验材料。
- [ ] 所有历史画面若为重建／AI 演示，不冒充真实原始记录。
- [ ] 整片画面优雅、统一、精密，字能读、数据能懂、镜头有因果。
- [ ] 完整渲染并进行视听检查；文件可以正常播放，首尾完整。

### 最终决策权

如果镜头数量、具体秒数、特效密度、预先推荐的素材与音乐结构冲突，**以准确表达、音画同步、整片完成度为先**。可以大胆优化镜头设计与技术路线，但不能擅自改掉核心科学事实、无旁白、统一视觉风格和音乐驱动的制作原则。
