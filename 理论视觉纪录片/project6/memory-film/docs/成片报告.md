# 《记忆会撒谎》制作报告

## 交付规格

横屏 1920×1080，30 fps，130 秒，3900 帧。唯一正式 Composition 为 MemoryLies。全片原创程序化 SVG 科学装置与动画，无旁白、无人物对白。音乐来自用户提供资产，另附原创合成 SFX 分轨。

成片：`../out/记忆会撒谎.mp4`。源工程：本目录上一级。最终技术结果见 `final-media.json`；抽帧检查见 `../qa/`。

## 参考与视觉实现

实际读取《运气的形状》风格分析文档，检查原片每 2 秒抽帧，覆盖片头到平台尾标共 133 秒。参考索引保存于 `qa/reference-0.jpg` 至 `reference-2.jpg`。这些是逐时刻画面观察，不能等同于主观连续播放和听辨。

采用暗场、低饱和金色、暖白、少量灰蓝、宋体、实验年代标签、胶片齿孔与精密标尺。原创装置为放映机、俯视碰撞、变量卡、双速度轴、独立样本点阵、七日刻度、玻璃隐喻、中文词卡、语义网络、双档案重建与合页闭合。未复制参考视频画面或素材。所有实验影像均标明情境重现，脑内结构不作为真实机制呈现。

## 音乐与时序

输入音乐 `../infomation/音乐/music-beat-pack/music.m4a`，来自用户《音乐.mp4》的原 AAC 音轨。配套 `配乐执行文档.md`、README 与 `music-beatmap.json` 均已读取。音频实测 192.8417 秒；文档拟合约 112.798 BPM，独立 librosa 粗网格估计为 112.347 BPM。后者受帧间隔量化影响，不据此覆盖已拟合的绝对时间点。

关键 cue 的独立 onset 检测大多比文档早 8–32 毫秒；主段进入分别检测为 17.438 与 102.539 秒，对应文档 17.459 与 102.567 秒。此处保留文档 cue，经每个绝对秒数独立四舍五入到 30 fps，避免累加漂移。`audio-verification.json` 保存全部检测记录。自动检测证明瞬态邻近关系，不证明人工听感重拍或拍号。

视频从音轨 0 秒开始。0–119.589 秒使用原连续音乐，最后 0.8 秒交叉淡化到原音轨 181.631 秒起的自然衰减，形成 130 秒尾声。末秒再做平滑淡出。混音 WAV 峰值限制为约 -1 dBFS，48 kHz 双声道；最终 AAC 编码后的测量见技术报告。未进行旁白合成。

主观连续试听尚未完成，尤其需听辨 118.789–119.589 秒的尾声交叉淡化。当前已完成的音频验证是波形、onset、峰值、解码和时间轴核对；不把这些写成已完成真人听感验收。

## 科学来源与边界

1. Loftus, E. F., & Palmer, J. C. (1974). *Reconstruction of automobile destruction: An example of the interaction between language and memory*. DOI: https://doi.org/10.1016/S0022-5371(74)80011-3 。校核版本：https://stanford.edu/class/psych205/papers/Loftus-Palmer-1974.pdf 。本地保存 `loftus1974-stanford.pdf`，表格图 `qa/paper-stanford.png`。
2. Roediger, H. L., & McDermott, K. B. (1995). *Creating false memories: Remembering words not presented in lists*. DOI: https://doi.org/10.1037/0278-7393.21.4.803 。作者所在大学研究页面：https://profiles.wustl.edu/en/publications/creating-false-memories-remembering-words-not-presented-in-lists/ 。论文 PDF 的本次读取超时，40%／55% 由论文索引及作者大学研究摘要交叉核验。

**来源差异记录：** PRD 所给 thegricean 扫描版的表 1 可见 40.8；Stanford 论文版表 1 为 40.5。影片保留 PRD 的 40.5，采用 Stanford 版本为数值校核依据。两版本均保存在 docs 中，不把差异归因于 OCR。

实验一五组均值为 31.8、34.0、38.1、39.3、40.5 mph。6.5 是两组平均估计之差，不是真实车速差，也不是单个人变化。实验二为新的 150 人，三组各 50，回答“看到了”分别为 16、7、6 人，即 32%、14%、12%。七日后未重播影片，原片无玻璃。

中文词表为本片范式示例；中心“睡眠”不在八个展示词中。40% 和 55% 属于原研究英文材料的关键诱饵词虚假自由回忆率，单独场景明确标注，不归给本片观众。所有档案与玻璃是视觉隐喻。

## 最终文件技术结果

130.000 秒视频，3900 帧，1920×1080，H.264 / yuv420p / 30 fps；AAC 双声道 48 kHz。完整解码通过，130 张逐秒抽帧已检查，覆盖起始、全部场景和尾声。最终数值以 final-media.json 为准。没有检测到削波采样；成片约 28 MB。词卡 SFX 已按实际入场时间修正，全部合成音效以绝对帧号对齐。

当前工具明确返回不支持音频输入，因此未将音频输出或自动检测冒充主观试听。连续听感尤其尾声剪接仍待人工审片。
