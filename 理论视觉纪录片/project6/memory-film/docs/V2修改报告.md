# V2：实体质感、汽车尺寸、字幕与节奏

新版文件：`../out/记忆会撒谎-v2.mp4`。1920×1080、30 fps、2471 帧、82.367 秒。原 130 秒版保留，缩短约 47.6 秒。

## 对应修改意见

- 放映机：去除方形金色外框和三角支架；圆角铸造机身、暗侧面、局部边缘反光、凹槽散热孔、镜筒环与镜片、底座接触阴影。仍为可编辑程序化模型。
- 汽车：所有 Film 装置内模型 scale 从 0.85 提高到 1.6，线性尺寸为原来 1.88 倍；重新调整相撞位置。覆盖开场、无碎玻璃画面、三份回忆版本及记忆档案。
- 字幕：从统一淡入淡出改为四种入场。短结论采用短促锁定；问题、语言与联想采用横向揭示；重建、记起采用上移收束；其余短句采用字距聚合。入场约 0.2 秒，退出约 0.12 秒，避免动画本身拖延。
- 节奏：逐段压缩动作时间，将结论字幕移至后部拍点。28 条底部字幕从出现到下一动作／段落的实际时间为 1.058–2.138 秒；不再普遍保留四秒以上的字幕后空等。所有列出的停留过长段落均纳入映射。
- “睡眠”段约 1.07 秒便接“它从未出现”；记忆档案四句分别约 2.13 秒一段，连续汇聚、分离、判断、关合。
- 结尾从约 10.4 秒缩至约 5.33 秒，包含档案闭合、最终命题、片名与来源及淡出；并非五秒不动的结论卡。

## 音乐与科学内容

音乐不变速。视频 0–68.533 秒对应原音乐 0 秒起；68.533 秒接原音乐 102.567 秒的主段 B，配合档案重建；77.033 秒接原音乐 164.803 秒起的衰减段。剪口使用短包络，结尾两秒淡出。所有原有 SFX 重新映射至新版绝对帧，见 `music-edit-v2.json`、`sfx-events-v2.json`。

实验数据、单位、独立样本、中文演示词表与隐喻说明保留。没有重做实验内容。此版本按本轮“缩短完成后的停留”要求低于初始 PRD 的建议时长。
